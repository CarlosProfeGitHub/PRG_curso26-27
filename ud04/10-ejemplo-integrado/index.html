    /*
 * Programa: GestionNotas
 * Descripción: Guarda las notas de los alumnos de una clase, calcula
 *              estadísticas, busca la nota más alta e imprime una
 *              tabla resumen por filas de alumnos.
 * Autor: Ana Pérez
 * Fecha: 2026-11-12
 */
import java.util.Arrays;

public class GestionNotas {

    static final int ALUMNOS_POR_FILA = 5;      // Columnas de la matriz resumen

    public static void main(String[] args) {

        // ---------- 1. Declaración y lectura ----------
        double[] notas = {7.5, 3.0, 9.0, 4.5, 8.0,
                          6.0, 10.0, 2.5, 5.5, 7.0};

        System.out.println("Notas: " + Arrays.toString(notas));
        System.out.println("Número de notas: " + notas.length);

        // ---------- 2. Recorrido: media, máximo y mínimo ----------
        double media = media(notas);
        double maximo = maximo(notas);
        double minimo = minimo(notas);

        System.out.println("Media : " + media);
        System.out.println("Máx   : " + maximo);
        System.out.println("Mín   : " + minimo);

        // ---------- 3. Búsquedas ----------
        System.out.println("Aprobados     : " + contarAprobados(notas));
        System.out.println("Suspensos     : " + contarSuspensos(notas));
        System.out.println("Nota más alta : " + maximo
                + " (posición " + posicionMaximo(notas) + ")");

        double suspensos[] = obtenerSuspensos(notas);   // Array devuelto por el método
        System.out.println("Lista         : " + Arrays.toString(suspensos));

        // ---------- 4. Ordenación (sobre una copia) ----------
        double[] ordenadas = ordenarCopia(notas);
        System.out.println("Ordenadas     : " + Arrays.toString(ordenadas));

        // ---------- 5. Matriz resumen ----------
        imprimirTabla(notas);
    }

    /** Función: devuelve la media de las notas. */
    static double media(double[] datos) {
        double suma = 0;
        for (int i = 0; i < datos.length; i++) {
            suma += datos[i];
        }
        return suma / datos.length;
    }

    /** Función: devuelve el mayor valor. Empezamos por el primer elemento. */
    static double maximo(double[] datos) {
        double max = datos[0];
        for (int i = 1; i < datos.length; i++) {
            if (datos[i] > max) {
                max = datos[i];
            }
        }
        return max;
    }

    /** Función: devuelve el menor valor. */
    static double minimo(double[] datos) {
        double min = datos[0];
        for (int i = 1; i < datos.length; i++) {
            if (datos[i] < min) {
                min = datos[i];
            }
        }
        return min;
    }

    /** Función: cuenta cuántos elementos cumplen una condición, con for-each. */
    static int contarAprobados(double[] datos) {
        int contador = 0;
        for (double nota : datos) {
            if (nota >= 5) {
                contador++;
            }
        }
        return contador;
    }

    /** Función sobrecargada: cuenta los suspensos con un for clásico. */
    static int contarSuspensos(double[] datos) {
        int contador = 0;
        for (int i = 0; i < datos.length; i++) {
            if (datos[i] < 5) {
                contador++;
            }
        }
        return contador;
    }

    /** Función: devuelve la posición del máximo. */
    static int posicionMaximo(double[] datos) {
        int pos = 0;
        for (int i = 1; i < datos.length; i++) {
            if (datos[i] > datos[pos]) {
                pos = i;                    // Guardamos el índice
            }
        }
        return pos;
    }

    /** Función: devuelve un array nuevo con los valores menores de 5. */
    static double[] obtenerSuspensos(double[] datos) {
        double[] suspensos = new double[contarSuspensos(datos)];
        int indice = 0;
        for (int i = 0; i < datos.length; i++) {
            if (datos[i] < 5) {
                suspensos[indice] = datos[i];
                indice++;
            }
        }
        return suspensos;
    }

    /** Función: devuelve una copia ordenada, sin tocar el array original. */
    static double[] ordenarCopia(double[] datos) {
        double[] copia = new double[datos.length];
        System.arraycopy(datos, 0, copia, 0, datos.length);
        Arrays.sort(copia);
        return copia;
    }

    /** Procedimiento: recorre una matriz con dos bucles anidados. */
    static void imprimirTabla(double[] datos) {
        int filas = (int) Math.ceil(datos.length / (double) ALUMNOS_POR_FILA);
        double[][] tabla = new double[filas][ALUMNOS_POR_FILA];

        // Llenamos la matriz recorriéndola por filas
        for (int f = 0; f < filas; f++) {
            for (int c = 0; c < ALUMNOS_POR_FILA; c++) {
                int indice = f * ALUMNOS_POR_FILA + c;
                if (indice < datos.length) {
                    tabla[f][c] = datos[indice];
                }
            }
        }

        System.out.println("\n--- TABLA DE NOTAS ---");
        for (int f = 0; f < tabla.length; f++) {
            for (int c = 0; c < tabla[f].length; c++) {
                System.out.printf("%5.1f ", tabla[f][c]);
            }
            System.out.println();
        }
    }
}

    Fíjate en los dos formatos de decimal

    La primera línea usa punto (7.5) y la tabla usa coma (7,5). No es un error:

    Origen Formato Por qué
    Arrays.toString() 7.5 Llama a Double.toString(), que siempre usa el punto.
    printf("%5.1f", …) 7,5 Usa la configuración regional del sistema, que en España es la coma.

    Es un comportamiento correctamente documentado de Java, y conviene conocerlo antes de extrañar.

    Dónde está cada cosa que aprendiste

    Apartado Dónde aparece en el programa
    Array 1D double[] notas y double[] suspensos
    .length En todos los bucles y en contarSuspensos()
    Recorrido ascendente media(), maximo(), minimo()
    Búsqueda contarAprobados() y contarSuspensos()
    for-each En contarAprobados()
    for clásico En todos los demás
    Guardar el índice posicionMaximo() necesita el i
    Devolver un array obtenerSuspensos() crea y devuelve un array nuevo
    Copia antes de ordenar ordenarCopia() con System.arraycopy
    Matriz imprimirTabla() con double[][] tabla
    Bucles anidados En el relleno y la impresión de la matriz
    Arrays.toString Para mostrar los arrays
    Arrays.sort Para ordenar la copia
    Piso y resto (int) Math.ceil(...) para calcular las filas

    Las tres decisiones que hacen que el programa funcione

    1. max empieza en datos[0], no en 0. Si algún día hay una nota de −1, el valor inicial 0 daría un máximo falso.

    2. obtenerSuspensos() reserva el array con una tamaño exacto. Primero cuenta (contarSuspensos), luego crea el array de ese tamaño, y solo entonces rellena. Si lo rellenara sin contar antes, necesitaría un array de tamaño 10 "por si acaso", con espacios sobrantes.

    3. imprimirTabla() comprueba indice < datos.length. Con 10 notas y 5 por fila no sobra ninguna, pero si fueran 11 habría una última casilla vacía. Esa comprobación es la que evita el ArrayIndexOutOfBoundsException.

    Antes de continuar

    1. Cambia ALUMNOS_POR_FILA a 3. ¿Cuántas filas tendrá la tabla? Comprueba que la última fila se rellena bien.
    2. Cambia ALUMNOS_POR_FILA a 4. Con 10 notas, la última fila tendrá un hueco vacío. ¿Qué imprime?
    3. Elimina la copia de ordenarCopia() y pasa datos directamente. ¿Qué cambia en el resultado?
