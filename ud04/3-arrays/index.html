    3. Arrays unidimensionales

    3.1. Qué es un array

    Definición

    Un array es una colección de elementos del mismo tipo que comparten un identificador común. Se accede a cada elemento de forma individual mediante un subíndice, que es la posición que ocupa dentro del array.

    Se numeran a partir del 0

    El primer subíndice de un array es el cero, y el último es la longitud del array menos uno.

    Índice:    0     1     2     3     4     5
        ┌─────┬─────┬─────┬─────┬─────┬─────┐
        │  12 │  7  │ 25  │  3  │ 18  │ 40  │
        └─────┴─────┴─────┴─────┴─────┴─────┘
        └───── El array "edad" tiene 6 elementos ─────┘
        0                    length = 6           5 (length - 1)

    Estático significa tamaño fijo

    El número de componentes de un array se establece al crearlo y no es posible cambiarlo. Por eso se llaman estructuras de datos estáticas.

    Si necesitas guardar 5 datos y luego llegan 7, no puedes agrandar el array: hay que crear otro más grande y copiar.

    int[] dias = new int[5];
dias[6] = 1;    // ❌ ArrayIndexOutOfBoundsException: índice 6 fuera de los límites

    3.2. Declaración y creación

    Para usar un array hay que hacer dos cosas: declararlo y crearlo.

    La declaración

    Indica el nombre de la variable y el tipo de los componentes:

    double lluvia1[];   // lluvia1 es un array de double
double[] lluvia2;   // lluvia2 es un array de double

    Las dos formas son equivalentes

    En Java da igual dónde pongas los corchetes: double lluvia1[] y double[] lluvia1 declaran exactamente lo mismo.

    La convención del curso

    Se escribe el tipo delante de los corchetes: double[] lluvia2;. Los corchetes pegados al nombre (lluvia1[]) son válidos, pero resultan difíciles de leer cuando hay varios.

    La creación

    Usa el operador new y establece el número de componentes:

    lluvia1 = new double[31];

    Las dos cosas juntas

    double[] lluvia2 = new double[31];

    El tamaño puede decidirse en tiempo de ejecución

    El número de elementos no tiene que ser un literal: puede ser cualquier expresión int.

    1

    Scanner teclado = new Scanner(System.in);

System.out.print("¿Cuántas personas hay en el grupo? ");
int numPersonas = teclado.nextInt();

// El array se dimensiona con un dato que acabamos de leer
int[] edad = new int[numPersonas];

    Esto es lo que hace los arrays útiles

    El tamaño puede depender de un dato del programa. Si el usuario dice que hay 25 personas, el array tiene 25 componentes. Esa flexibilidad es la que no podrías conseguir con 25 variables sueltas.

    3.3. Acceso a los componentes

    La sintaxis de acceso es:

    nombreVariable[subíndice]

    Una vez declarado lluvia con 31 componentes double, numerados del 0 al 30:

    Expresión Elemento
    lluvia[0] Primer día
    lluvia[1] Segundo día
    lluvia[2] Tercer día
    … …
    lluvia[30] Último día

    Cada componente admite todas las operaciones de una variable normal de su tipo:

    1
2
3
4
5

7
    System.out.print("Introduce el dato para el componente 0: ");
edad[0] = teclado.nextInt();        // El usuario escribe 25

System.out.println("El componente [0] vale " + edad[0]);   // 25
edad[1] = edad[0] + 1;              // 26
edad[2] = edad[0] + edad[1];        // 51
edad[2]++;                          // 52

    El subíndice puede ser una expresión

    No tiene que ser un número literal: puede ser cualquier expresión entera.

    1
2
3
    int i;
edad[i] = edad[i + 1];
edad[i + 2] = edad[i];

    El error más común de toda la unidad

    Confundir el subíndice con el valor. Estas dos líneas no hacen lo mismo:

    edad[25] = 5;      // Asigna 5 al array, en la posición 25
edad = 25;         // ❌ ERROR: no se puede asignar un int a un int[]

    Y esta otra tampoco:

    edad[5];           // Lee el valor guardado en la posición 5

    La regla mental: lo que va dentro de los corchetes es siempre la POSICIÓN, no el dato.

    3.4. Inicialización

    Java inicializa automáticamente los componentes de un array recién creado:

    Tipo de componente Valor inicial
    Numéricos (int, double, long…) 0
    boolean false
    char El carácter de ASCII \0
    Objetos (String, etc.) null

    ¿Por qué importa esto?

    Porque significa que new int[5] no contiene basura: contiene cinco ceros. Si recorres el array antes de rellenarlo, no obtendrás valores aleatorios, sino ceros.

    Forma 1 · Inicialización individual

    1
2
3
4
5
    int[] edad = new int[10];
edad[0] = 25;
edad[1] = 10;
// ...
edad[9] = 12;

    Forma 2 · Inicialización en la declaración

    Entre llaves, con los valores separados por comas. En este caso no hace falta new: Java crea el array con tantos componentes como valores hayas escrito.

    1
    int[] edad = {25, 10, 23, 34, 65, 23, 1, 67, 54, 12};

    El tamaño se deduce solo

    No hay que escribir new int[10]: Java cuenta los valores de las llaves. Es la forma más cómoda de escribir un array con datos conocidos.

    Un ejemplo práctico: el nombre de los meses

    Este es el problema de "devolver el nombre de un mes dado su número" resuelto en las UD anteriores, ahora con un array:

     1

    /**
 * Devuelve el nombre del mes indicado.
 *
 * @param mes número del mes, del 1 al 12
 * @return el nombre del mes
 */
public static String nombreMes(int mes) {
    String[] nombre = {" ", "enero", "febrero", "marzo", "abril",
                       "mayo", "junio", "julio", "agosto",
                       "septiembre", "octubre", "noviembre", "diciembre"};
    return nombre[mes];
}

    El componente 0 está vacío a propósito

    String[] nombre = {" ", "enero", "febrero", …};
//                  ↑    ↑        ↑
//                pos 0  pos 1   pos 2

    La primera posición es " " porque los meses van del 1 al 12, pero los índices del 0 al 12. Así, nombre[1] es "enero" y nombre[12] es "diciembre", y la búsqueda se reduce a nombre[mes].

    Esa es una trampa clásica

    Si el array empezara por "enero" en la posición 0, habría que devolver nombre[mes - 1], y para el mes 12 o el mes 13 el resultado sería "null" o un error. Piensa siempre en el desplazamiento.

    La alternativa sin desplazamiento

    Se puede crear un array de 12 elementos empezando en "enero" y trabajar con mes - 1:

    String[] nombre = {"enero", "febrero", …, "diciembre"};
return nombre[mes - 1];

    Las dos formas son válidas. Elige una y mantenla en todo el programa: mezclar ambas es la fuente clásica de errores "off by one".
