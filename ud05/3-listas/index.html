    3. Listas (List)

    La interfaz List define una sucesión ordenada de elementos. A diferencia de los conjuntos (Set), las listas sí admiten elementos duplicados.

    Añade a la interfaz básica Collection métodos específicos para gestionar posiciones exactas:

    • Acceso posicional: manipula y consulta elementos a partir de su índice numérico (de 0 a size() - 1).
    • Búsqueda por valor: busca un objeto y devuelve su primera (indexOf) o última posición (lastIndexOf).
    • Iteración bidireccional: mediante listIterator(), permite recorrer la lista tanto hacia adelante como hacia atrás y modificar elementos durante la marcha.
    • Operaciones de rango: permite extraer vistas parciales de la lista con subList(from, to).

    3.1. Implementaciones de List

    Implementación Estructura interna Rendimiento acceso Rendimiento inserción/borrado Sincronización
    ArrayList Array redimensionable dinámicamente Inmediato $O(1)$ por índice Lento en medio/inicio $O(N)$ (desplaza elementos) No (rápido)
    LinkedList Lista doblemente enlazada (nodos) Secuencial $O(N)$ Rápido $O(1)$ en extremos si se tiene el nodo No
    Vector Array redimensionable sincronizado Inmediato $O(1)$ Lento en medio/inicio $O(N)$ Sí (Thread-Safe, más lento)
    • ArrayList: es la implementación predeterminada y más recomendada para la gran mayoría de casos de uso prácticos.
    • LinkedList: implementa simultáneamente List, Queue y Deque. Resulta ventajosa si se realizan inserciones y eliminaciones continuas al inicio o al final de la colección.
    • Vector: implementación histórica de Java 1.0. Sus métodos están sincronizados para concurrencia entre hilos, lo que introduce una sobrecarga innecesaria en programas monohilo.

    Criterio de elección: ¿ArrayList o LinkedList?

    • Usa ArrayList en el 95% de los casos: consume menos memoria, aprovecha la memoria caché del procesador y ofrece lectura inmediata $O(1)$ por índice.
    • Usa LinkedList únicamente si vas a realizar continuas inserciones o borrados en el primer elemento de la lista (como una cola o pila) y rara vez accedes por índice numérico intermedio.

    3.2. Métodos más utilizados de ArrayList

    Método Descripción
    int size() Devuelve el número de elementos contenidos en la lista.
    boolean add(E x) Añade el objeto x al final de la lista. Devuelve true.
    void add(int posicion, E x) Inserta el objeto x en la posición indicada, desplazando los elementos siguientes.
    E get(int posicion) Devuelve el elemento situado en la posición indicada.
    E remove(int posicion) Elimina el elemento de la posición indicada y lo devuelve. Desplaza los siguientes a la izquierda.
    boolean remove(Object x) Elimina la primera ocurrencia del objeto x. Devuelve true si estaba presente.
    void clear() Elimina todos los elementos de la lista.
    E set(int posicion, E x) Sustituye el elemento de la posición indicada por x. Devuelve el elemento sustituido.
    boolean contains(Object x) Comprueba si la lista contiene el objeto x.
    int indexOf(Object x) Devuelve el índice de la primera ocurrencia de x, o -1 si no existe.
    int lastIndexOf(Object x) Devuelve el índice de la última ocurrencia de x, o -1 si no existe.
    List<E> subList(int from, int to) Devuelve una vista de los elementos desde from (incluido) hasta to (excluido).

    import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

public class EjemploListas {
    public static void main(String[] args) {
        // Declaramos la variable usando la interfaz List e instanciamos ArrayList
        List<String> lenguajes = new ArrayList<>();

        // Añadir elementos al final
        lenguajes.add("Java");
        lenguajes.add("Python");
        lenguajes.add("C++");

        // Insertar en una posición específica
        lenguajes.add(1, "JavaScript");

        // Consultar por índice
        System.out.println("Primer lenguaje: " + lenguajes.get(0)); // Java

        // Modificar un elemento
        lenguajes.set(2, "TypeScript");

        // Búsqueda
        int pos = lenguajes.indexOf("C++");
        System.out.println("C++ está en la posición: " + pos);

        // Ordenar la lista alfabéticamente
        Collections.sort(lenguajes);
        System.out.println("Lista ordenada: " + lenguajes);

        // Eliminar elementos
        lenguajes.remove("TypeScript");
        lenguajes.remove(0);
        lenguajes.clear();
    }
}

    3.3. Formas de recorrer una lista

    Existen tres formas estándar de recorrer los elementos de una lista en Java:

    3.3.1. Bucle for clásico con índice

    Permite conocer y utilizar el índice de la posición actual:

    for (int i = 0; i < lenguajes.size(); i++) {
    System.out.println("Posición " + i + ": " + lenguajes.get(i));
}

    3.3.2. Bucle for-each mejorado

    La forma más limpia y legible cuando no necesitamos manipular los índices numéricos:

    for (String lang : lenguajes) {
    System.out.println("Lenguaje: " + lang);
}

    3.3.3. Recorrido con Iterator o ListIterator

    Recomendado cuando necesitamos eliminar elementos de la lista mientras la recorremos (evita la excepción ConcurrentModificationException):

    import java.util.Iterator;

Iterator<String> it = lenguajes.iterator();
while (it.hasNext()) {
    String lang = it.next();
    if (lang.equals("C++")) {
        it.remove(); // Eliminación segura durante el recorrido
    }
}

    Puente con la UD04

    El bucle for clásico con índice es el mismo que usabas con arrays: solo cambia v.length por lista.size() y v[i] por lista.get(i). La diferencia es que ahora el tamaño puede cambiar.
