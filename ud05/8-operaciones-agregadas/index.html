    8. Operaciones agregadas y selección de colección

    A lo largo de esta unidad hemos estudiado las principales familias de estructuras de datos dinámicas que componen el Java Collections Framework (JCF): listas (List), conjuntos (Set), colas (Queue), pilas (Stack / Deque) y mapas (Map).

    En las aplicaciones reales, rara vez se utiliza una sola colección de forma aislada. Lo habitual es combinar varias de ellas, asignando a cada necesidad del modelo de datos la estructura más eficiente y apropiada.

    8.1. Operaciones agregadas

    Las operaciones agregadas son métodos que actúan sobre conjuntos de elementos en lugar de sobre elementos individuales. Permiten combinar, filtrar y transformar colecciones de forma declarativa.

    8.1.1. Operaciones entre colecciones

    Método Descripción Equivalente matemático
    addAll(Collection c) Añade todos los elementos de c. Unión
    removeAll(Collection c) Elimina los elementos presentes en c. Diferencia
    retainAll(Collection c) Mantiene solo los elementos presentes en c. Intersección
    containsAll(Collection c) Comprueba si contiene todos los elementos de c. Subconjunto

    Set<String> s1 = new HashSet<>(Set.of("A", "B", "C"));
Set<String> s2 = new HashSet<>(Set.of("B", "C", "D"));

Set<String> union = new HashSet<>(s1);
union.addAll(s2); // {A, B, C, D}

Set<String> interseccion = new HashSet<>(s1);
interseccion.retainAll(s2); // {B, C}

Set<String> diferencia = new HashSet<>(s1);
diferencia.removeAll(s2); // {A}

    8.1.2. Operaciones sobre los elementos

    Método Descripción
    forEach(Consumer) Ejecuta una acción para cada elemento (Java 8+).
    removeIf(Predicate) Elimina los elementos que cumplen una condición.
    stream() Abre un flujo para procesar la colección (Java 8+). 
    // Recorrido con forEach y lambda
lista.forEach(e -> System.out.println(e));

// Eliminación condicional
lista.removeIf(e -> e < 0);

// Operación agregada con stream
double media = lista.stream()
                   .mapToInt(Integer::intValue)
                   .average()
                   .orElse(0.0);

    ¿Cuándo usar operaciones agregadas?

    • Usa addAll/removeAll/retainAll para combinar colecciones (unión, diferencia, intersección).
    • Usa removeIf para filtrados simples.
    • Usa stream() cuando necesites transformar, filtrar y agregar en una sola expresión.

    8.2. ¿Cómo elegir la colección adecuada?

    Seleccionar la colección idónea para cada problema es una competencia fundamental en el diseño de software.

    Colección Interfaz Duplicados Ordenación Complejidad búsqueda Caso de uso típico
    ArrayList List Sí Inserción (por índice) $O(N)$ / $O(1)$ por índice Listados generales, iteración frecuente, acceso por índice.
    LinkedList List, Deque Sí Inserción $O(N)$ Inserciones y borrados constantes en extremos o como cola/deque.
    HashSet Set No Ninguno $O(1)$ Evitar duplicados con máxima velocidad de comprobación.
    LinkedHashSet Set No Inserción $O(1)$ Evitar duplicados manteniendo el orden en que entraron.
    TreeSet Set No Natural / Comparator $O(\log N)$ Conjunto sin duplicados siempre ordenado de menor a mayor.
    HashMap Map Claves: No / Valores: Sí Ninguno $O(1)$ Diccionarios, búsquedas por DNI, ID, código o clave única.
    LinkedHashMap Map Claves: No / Valores: Sí Inserción $O(1)$ Mapas clave-valor recordando el orden de llegada.
    TreeMap Map Claves: No / Valores: Sí Claves ordenadas $O(\log N)$ Diccionarios con claves ordenadas alfabética o numéricamente.
    PriorityQueue Queue Sí Por prioridad $O(\log N)$ inserción Procesar tareas según nivel de urgencia o prioridad.
    ArrayDeque Deque Sí Inserción $O(1)$ Pilas (LIFO) y colas (FIFO) eficientes en Java moderno.
