    4. Iteradores

    Un iterador es un objeto que permite recorrer una colección elemento a elemento sin exponer su estructura interna. Es la forma recomendada de recorrer una colección cuando necesitamos eliminar elementos durante el recorrido.

    4.1. La interfaz Iterator<E>

    Método Descripción
    boolean hasNext() Devuelve true si quedan elementos por recorrer.
    E next() Devuelve el siguiente elemento y avanza el cursor.
    void remove() Elimina el último elemento devuelto por next(). Solo se puede llamar una vez por next().

    import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;

public class FiltradoSeguro {
    public static void main(String[] args) {
        List<Double> precios = new ArrayList<>();
        for (int i = 0; i < 10; i++) {
            precios.add(5.0 + Math.random() * 95.0);
        }

        double minimo = 30.0;

        // ❌ Incorrecto: ConcurrentModificationException
        // for (Double p : precios) {
        //     if (p < minimo) precios.remove(p);
        // }

        // ✅ Correcto: Iterator
        Iterator<Double> it = precios.iterator();
        while (it.hasNext()) {
            Double p = it.next();
            if (p < minimo) {
                it.remove(); // Eliminación segura
            }
        }

        System.out.println("Precios filtrados: " + precios);
    }
}

    Por qué falla el for-each

    El bucle for-each utiliza internamente un iterador. Si modificamos la colección directamente (lista.remove(...)) mientras el iterador está activo, Java lanza ConcurrentModificationException para evitar estados inconsistentes.

    4.2. ListIterator: recorrido bidireccional

    ListIterator extiende Iterator y solo está disponible en las listas. Permite recorrer en ambos sentidos y modificar elementos:

    Método adicional Descripción
    boolean hasPrevious() Comprueba si hay elemento anterior.
    E previous() Retrocede y devuelve el elemento anterior.
    int nextIndex() / previousIndex() Devuelve el índice del siguiente/anterior.
    void set(E e) Reemplaza el último elemento devuelto.
    void add(E e) Inserta un elemento en la posición actual. 
    import java.util.ListIterator;

ListIterator<String> lit = lenguajes.listIterator();
while (lit.hasNext()) {
    String lang = lit.next();
    if (lang.equals("Python")) {
        lit.set("PyPy"); // Reemplaza Python por PyPy
    }
}

    4.3. Eliminación moderna con removeIf

    Desde Java 8, la interfaz Collection incorpora el método removeIf(Predicate), que elimina los elementos que cumplen una condición en una sola línea:

    precios.removeIf(p -> p < 30.0);

    ¿Iterator o removeIf?

    • Usa Iterator cuando la lógica de eliminación sea compleja o necesites hacer otras operaciones durante el recorrido.
    • Usa removeIf para filtrados simples y legibles.

    4.4. Comparación de formas de recorrer

    Forma ¿Conoce el índice? ¿Puede eliminar? ¿Puede ir hacia atrás?
    for clásico con índice Sí No directamente Sí (con i--)
    for-each No No No
    Iterator No Sí (con remove()) No
    ListIterator Sí Sí Sí
    removeIf No Sí No

    Puente con la UD04

    En la UD04 recorrías arrays con for. Con colecciones, el recorrido sigue siendo un for, pero ahora dispones de herramientas de más alto nivel que evitan errores de índice.
