    7. Mapas (Map)

    La interfaz Map<K, V> asocia pares de claves (Key) y valores (Value). No implementa la interfaz Collection, pero forma parte integral de la arquitectura del Java Collections Framework.

    • Claves únicas: un mapa no puede contener claves duplicadas. Cada clave identifica unívocamente a un registro.
    • Valores asociados: cada clave puede tener asociado un único valor como máximo (los valores sí pueden repetirse entre diferentes claves).
    • Si insertamos un par cuya clave ya existe en el mapa mediante .put(clave, nuevoValor), el valor anterior se sobrescribe y el método retorna el valor que estaba previamente asociado.

    7.1. Implementaciones principales de Map

    7.1.1. HashMap

    • Almacena los pares internamente en una tabla hash.
    • Ofrece el mejor rendimiento de todas las implementaciones: tiempo constante $O(1)$ en operaciones básicas (put, get, remove, containsKey).
    • No garantiza ningún orden en las claves ni en las iteraciones sobre ellas.
    • Permite una clave null y múltiples valores null.

    7.1.2. TreeMap

    • Almacena las claves ordenadas en función de sus valores según su orden natural (Comparable) o mediante un Comparator.
    • Implementa la interfaz NavigableMap mediante una estructura interna de árbol rojo-negro, garantizando tiempos de acceso y modificación de $O(\log N)$.
    • No permite claves null.

    7.1.3. LinkedHashMap

    • Conserva los pares ordenados en función de su orden de inserción (o en función del orden de último acceso).
    • Ligeramente más costosa en memoria y tiempo que HashMap por mantener una lista doblemente enlazada, pero mucho más rápida que TreeMap.

    7.2. Métodos principales de la interfaz Map<K, V>

    Método Descripción
    V put(K clave, V valor) Asocia la clave con el valor. Si la clave ya existía, devuelve el valor antiguo; si no, null.
    V get(Object clave) Devuelve el valor asociado a la clave, o null si la clave no existe en el mapa.
    V remove(Object clave) Elimina la clave y su valor asociado. Devuelve el valor que tenía asignado.
    boolean containsKey(Object clave) Devuelve true si el mapa contiene una asociación para la clave indicada.
    boolean containsValue(Object valor) Devuelve true si uno o más claves apuntan al valor indicado.
    int size() Devuelve el número total de pares clave-valor almacenados.
    boolean isEmpty() Retorna true si el mapa no contiene ninguna asociación.
    void clear() Elimina todas las entradas del mapa.
    Set<K> keySet() Devuelve una vista en forma de conjunto (Set) con todas las claves del mapa.
    Collection<V> values() Devuelve una colección (Collection) con todos los valores almacenados.
    Set<Map.Entry<K, V>> entrySet() Devuelve un conjunto de entradas (pares clave-valor) para iterar eficientemente.

    7.3. Formas de recorrer un Map

    Para recorrer un mapa no podemos utilizar un bucle for tradicional por índice ni iterar directamente sobre el mapa, ya que no implementa Iterable. Java proporciona tres vistas para recorrerlo:

    7.3.1. Recorrido por claves con keySet()

    Obtenemos el conjunto de claves y pedimos el valor asociado a cada una mediante .get():

    for (String clave : mapa.keySet()) {
    System.out.println("Clave: " + clave + " -> Valor: " + mapa.get(clave));
}

    7.3.2. Recorrido por valores con values()

    Cuando solo nos interesan los valores y no necesitamos conocer las claves:

    for (Double valor : mapa.values()) {
    System.out.println("Valor: " + valor);
}

    7.3.3. Recorrido por pares de entrada con entrySet() (Recomendado)

    Es la opción más eficiente porque obtiene simultáneamente la clave y el valor en cada iteración sin necesidad de hacer una segunda búsqueda con .get():

    for (Map.Entry<String, Double> entrada : mapa.entrySet()) {
    System.out.println("Clave: " + entrada.getKey() + " | Valor: " + entrada.getValue());
}

    import java.util.HashMap;
import java.util.Map;

public class EjemploMapas {
    public static void main(String[] args) {
        Map<String, Double> productos = new HashMap<>();

        // Insertar pares clave-valor
        productos.put("Teclado", 29.99);
        productos.put("Ratón", 15.50);
        productos.put("Monitor", 189.00);

        // Sobrescribir valor
        productos.put("Ratón", 19.99);

        // Consultar valor por clave
        System.out.println("Precio del monitor: " + productos.get("Monitor") + " €");

        // Consultar con valor por defecto
        double precioAltavoces = productos.getOrDefault("Altavoces", 0.0);
        System.out.println("Precio altavoces: " + precioAltavoces + " €");

        // Comprobaciones
        System.out.println("¿Existe 'Teclado'?: " + productos.containsKey("Teclado"));
    }
}

    Puente con la UD04

    Un mapa es, en esencia, un array de asociaciones clave-valor. La diferencia es que la "posición" ya no es un número, sino un objeto (la clave), y el tamaño crece dinámicamente.
