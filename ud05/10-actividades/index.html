    10. Actividades

    Organiza tu entrega

    Crea la carpeta ud05/bloque1 (o bloque2, bloque3…) y guarda dentro las actividades del bloque correspondiente.

    Antes de entregar cualquier actividad

    • No uses tamaños fijos cuando puedas usar .size().
    • Recuerda: las colecciones solo admiten objetos. Usa Integer, no int.
    • Programa contra interfaces (List, Set, Map), no contra clases concretas.
    • Ningún método debe leer del teclado: lee en main y pasa la colección como parámetro.

    Bloque 5.1 · La librería ArrayList

    Actividad 01 · Ordenar listas

    Crea un programa que cree un ArrayList<Integer> con 15 números enteros aleatorios. Ordénalo usando Collections.sort(lista).

    Repite la operación con un ArrayList<Double> y un ArrayList<String>. Muestra los resultados por pantalla.

    Actividad 02 · Buscar en una lista ordenada

    Crea un programa que genere un ArrayList<Integer> con 5 números aleatorios entre 1 y 10. Ordénalo usando Collections.sort(lista).

    A continuación, pide al usuario un número entre 1 y 10 e indica si se encuentra o no en la lista usando lista.contains(numero).

    Actividad 03 · Comparar listas

    Crea dos ArrayList. Después comprueba si son exactamente iguales usando el método lista1.equals(lista2). Muestra el resultado por pantalla.

    Actividad 04 · Invertir una lista

    Crea un programa que genere un ArrayList con 7 valores aleatorios entre 1 y 100. Rellena otro ArrayList con los mismos valores, pero en orden inverso. Para ello, puedes usar el método Collections.reverse(lista). Muestra ambos ArrayList por pantalla.

    Actividad 05 · Copiar una lista

    Crea un ArrayList<Integer> con 15 números enteros aleatorios. Después crea una copia exacta utilizando el constructor:

    ArrayList<Integer> copia = new ArrayList<>(original);

    Muestra ambas listas por pantalla.

    Actividad 06 · Estadísticas de una lista

    Crea un ArrayList<Integer> con 10 números aleatorios. Calcula y muestra:

    • La suma total.
    • La media de los elementos.
    • El número más grande.
    • El número más pequeño.

    Actividad 07 · Gestor de tareas

    Crea un menú que permita gestionar una lista de tareas usando un ArrayList<String>.

    Opciones:

    • Añadir tarea.
    • Mostrar tareas.
    • Eliminar tarea.
    • Buscar tarea.
    • Salir.

    El programa deberá ejecutarse hasta que el usuario elija salir.

    Actividad 08 · Filtro de precios con wrappers

    Contexto: Una tienda online necesita filtrar su catálogo de precios según el presupuesto del cliente. En esta actividad practicamos el uso de clases envoltorio (Double, Integer) con ArrayList.

    Crea la clase FiltroPreciosWrapper:

    1. Genera un ArrayList<Double> con 12 precios aleatorios entre 5.0 y 150.0.
    2. Pide al usuario un precio máximo (double) usando Double.parseDouble() para convertir la entrada del Scanner.
    3. Crea el método public static ArrayList<Double> filtrarPorPrecio(ArrayList<Double> precios, double max) que devuelva una nueva lista solo con los precios menores o iguales al máximo.
    4. Muestra la lista original y la lista filtrada.
    5. Muestra también el precio más alto de la lista filtrada usando Collections.max().

    Actividad 09 · Convertidor de tipos

    Contexto: Practicamos el uso de las clases envoltorio (Integer, Double, Boolean, Character) para convertir tipos y validar datos.

    Crea la clase ConvertidorTipos con los siguientes métodos estáticos:

    1. public static boolean esEntero(String s): intenta convertir s a entero con Integer.parseInt(). Si lanza NumberFormatException, devuelve false; si tiene éxito, devuelve true.
    2. public static boolean esDecimal(String s): igual pero con Double.parseDouble().
    3. public static int sumarDigitos(int n): convierte el entero a String con Integer.toString(n), recorre los caracteres con charAt(), convierte cada dígito a entero con Character.getNumericValue() y devuelve la suma.
    4. public static String aBinario(int n): devuelve la representación binaria del entero usando Integer.toBinaryString(n).
    5. public static String aHexadecimal(int n): devuelve la representación hexadecimal usando Integer.toHexString(n).

    En el main, pide un número al usuario como String:

    • Comprueba si es entero o decimal con tus métodos.
    • Si es entero: muestra la suma de sus dígitos, su representación binaria y hexadecimal.
    • Si no es número válido: muestra un mensaje de error.

    Bloque 5.2 · Mapas

    Actividad 10 · Votaciones

    Paquete: A1_votaciones

    Crea un programa que simule una encuesta sobre el lenguaje de programación favorito.

    1. Usa un HashMap<String, Integer> donde la clave sea el nombre del lenguaje y el valor la cantidad de votos.
    2. Añade, al menos, 5 lenguajes de programación (con valor 0 al principio).
    3. Pide al usuario que vaya introduciendo votos (hasta 15).
    4. Cada vez que se repita un lenguaje, incrementa su contador.
    5. Al final, muestra todos los lenguajes con su número de votos e indica cuál fue el lenguaje más votado.

    Actividad 11 · Inventario de librería

    Paquete: A2_libreria

    Desarrolla un sistema sencillo para gestionar el inventario de una librería.

    1. Usa un HashMap<String, Integer> donde la clave sea el nombre del libro y el valor la cantidad disponible en stock.
    2. Realizar métodos para agregar nuevos libros, vender un libro (disminuir stock), mostrar el inventario completo y mostrar solo los libros con menos de 5 unidades.

    Si se intenta vender un libro inexistente o sin stock, mostrar un mensaje de error.

    Crea un menú de usuario para las distintas acciones.

    Actividad 12 · Agenda telefónica

    Agrega métodos para:

    1. Agregar un contacto.
    2. Buscar un contacto por su nombre.
    3. Eliminar un contacto.
    4. Mostrar todos los contactos almacenados.

    En el método main, crea un menú para que el usuario pueda realizar las distintas acciones.

    Actividad 13 · Notas de estudiantes

    Paquete: A4_notasEstudiantes

    Se desea crear un sistema que almacene las calificaciones de varios estudiantes.

    Para ello, se usará un HashMap<String, ArrayList<Double>>, donde la clave sea el nombre del estudiante y el valor su lista de notas.

    Agrega métodos para:

    1. Agregar nuevos estudiantes.
    2. Agregar notas a estudiantes ya almacenados.
    3. Calcular la nota media de un estudiante.
    4. Mostrar todos los estudiantes almacenados con sus notas.

    En el método main, crea un menú para que el usuario pueda realizar las distintas acciones.

    Además, crea otro HashMap<String, Integer> que contenga las mismas palabras en español y la cuenta de las veces que se ha consultado cada palabra.

    Añade, al menos, 15 palabras al sistema.

    Agrega métodos para:

    2. Introducir una palabra en español y que el sistema muestre su traducción si existe.
    3. Mostrar cuántas veces se ha mostrado una palabra en concreto.
    4. Mostrar cuántas veces se han mostrado cada una de las palabras.
    5. Mostrar todas las traducciones almacenadas.

    En el método main, crea un menú para que el usuario pueda realizar las distintas acciones.

    Actividad 15 · Pedidos

    Paquete: A6_pedidos

    Una tienda online quiere registrar los productos que compra cada cliente. Usa HashMap<String, ArrayList<String>>, donde la clave sea el DNI del cliente y el valor los códigos de los productos comprados.

    Agrega métodos para:

    1. Permitir registrar compras. Si el usuario ya existe, se añade el producto comprado a su lista. Si no existe, se crea automáticamente.
    2. Mostrar todos los clientes con sus productos.
    3. Eliminar un cliente y toda su lista de productos comprados.

    EXTRA: Evitar duplicados si el cliente compra varias veces el mismo producto.

    En el método main, crea un menú para que el usuario pueda realizar las distintas acciones.

    Bloque 5.3 · Conjuntos, pilas, colas e iteradores

    Actividad 20 · Eliminar duplicados

    Escribe un programa que solicite al usuario nombres de personas o productos por teclado de forma continuada hasta que el usuario escriba la palabra "fin".

    1. Almacena todos los elementos introducidos en un HashSet<String> para eliminar automáticamente cualquier valor duplicado. Muestra por pantalla el total de elementos únicos y el contenido del conjunto.
    2. Vuelca el contenido en un TreeSet<String> y muéstralo por pantalla. Comprueba cómo ahora los nombres aparecen automáticamente ordenados en orden alfabético.
    3. Finalmente, pide un nombre al usuario y comprueba si dicho nombre está presente en el conjunto utilizando el método .contains().

    Actividad 21 · Operaciones con conjuntos

    En un centro de estudios se ofertan dos cursos intensivos extracurriculares: "Desarrollo Web" y "Ciberseguridad".

    Crea dos conjuntos Set<String> para almacenar los nombres de los alumnos matriculados en cada curso (introduce al menos 5 alumnos en cada uno, asegurándote de que haya al menos 2 alumnos matriculados en ambos cursos a la vez).

    Realiza las siguientes operaciones matemáticas de conjuntos y muestra los resultados:

    1. Intersección (retainAll): obtén y muestra la lista de alumnos que están cursando ambos cursos simultáneamente.
    2. Unión (addAll): obtén y muestra la lista completa de todos los alumnos que asisten a al menos uno de los dos cursos (sin duplicar los nombres comunes).
    3. Diferencia (removeAll): obtén y muestra la lista de alumnos matriculados exclusivamente en Desarrollo Web (que no cursan Ciberseguridad).

    Actividad 22 · Cola de impresión

    Simula el funcionamiento de la cola de impresión compartida de una empresa mediante una estructura de tipo Cola (FIFO) utilizando la interfaz Queue<String> implementada mediante LinkedList o ArrayDeque.

    El programa mostrará un menú interactivo con las siguientes opciones:

    1. Enviar documento a imprimir: pide el nombre del archivo y lo añade al final de la cola mediante .offer().
    2. Imprimir siguiente trabajo: extrae y procesa el documento situado al frente de la cola mediante .poll(). Si la cola está vacía, debe avisar al usuario.
    3. Consultar trabajo en cabecera: muestra el nombre del documento que se va a imprimir a continuación sin retirarlo de la cola mediante .peek().
    4. Ver estado de la cola: muestra cuántos documentos quedan pendientes (.size()) y la lista de todos ellos.
    5. Salir.

    Actividad 23 · Pila de navegador

    Simula el botón de retroceso (historial hacia atrás) de un navegador web mediante una estructura de tipo Pila (LIFO) utilizando la interfaz Deque<String> implementada mediante ArrayDeque.

    El programa permitirá al usuario:

    1. Visitar nueva página: pide una URL por teclado y la apila en la cima mediante .push().
    2. Botón Atrás (retroceder): desapila la página actual mediante .pop() y muestra la página a la que se regresa. Si no quedan páginas en el historial para retroceder, muestra un mensaje de aviso.
    3. Página actual: muestra la URL en la que nos encontramos actualmente mediante .peek() sin modificar la pila.
    4. Historial completo: muestra todas las páginas almacenadas en la pila de retroceso.
    5. Salir.

    Actividad 24 · Filtrado seguro

    Crea una lista List<Double> con 10 precios de productos introducidos por el usuario o generados aleatoriamente entre 5.0 y 100.0 €.

    Pide al usuario un precio mínimo (por ejemplo, 30.0 €). El objetivo es eliminar de la lista todos los precios que sean estrictamente inferiores a dicho umbral:

    1. Explica en un comentario por qué fallaría el programa si intentáramos eliminar los elementos mediante lista.remove(precio) dentro de un bucle for-each ordinario (haciendo mención a ConcurrentModificationException).
    2. Implementa la eliminación de forma segura utilizando un Iterator<Double> y su método .remove().
    3. Vuelve a probar la misma lógica pero resolviéndolo en una sola línea mediante el método moderno .removeIf() y una expresión lambda.
    4. Muestra la lista final de precios resultante tras el filtrado.

    Actividad 25 · Diccionario de sinónimos

    Crea un sistema de consulta de sinónimos utilizando un mapa en el que a cada palabra clave le corresponde una lista dinámica de sinónimos: Map<String, List<String>>.

    1. Inicializa el mapa con al menos 4 palabras y sus correspondientes listas de sinónimos (ejemplo: "rápido" → ["veloz", "ágil", "ligero"], "difícil" → ["complejo", "arduo", "complicado"]).
    2. Pide una palabra al usuario. Si existe en el mapa, muestra todos sus sinónimos.
    3. Si la palabra no existe en el diccionario, informa al usuario y dale la opción de añadirla pidiendo por teclado dos sinónimos para agregarla dinámicamente al mapa.
    4. Muestra el diccionario completo ordenado alfabéticamente por clave (usando un TreeMap o recorriendo con entrySet()) con formato claro y tabulado.
