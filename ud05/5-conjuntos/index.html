    5. Conjuntos (Set)

    La interfaz Set define una colección que no puede contener elementos duplicados. Modela la abstracción matemática de un conjunto.

    • Contiene únicamente los métodos heredados de Collection, añadiendo la restricción estricta de prohibir duplicados.
    • Si intentamos añadir un elemento que ya existe mediante .add(), la operación no produce error ni lanza excepciones, sino que simplemente retorna false y el conjunto permanece inalterado.
    • Cálculo de duplicados: para que un conjunto determine si dos elementos son idénticos, es indispensable que los objetos almacenados tengan implementados correctamente los métodos equals(Object o) y hashCode().
    • Igualdad de conjuntos: dos conjuntos se consideran iguales (set1.equals(set2)) si contienen exactamente los mismos elementos, sin importar el orden en que se encuentren almacenados.

    5.1. Implementaciones principales de Set

    5.1.1. HashSet

    • Almacena los elementos internamente en una tabla hash.
    • Es la implementación con mejor rendimiento de todas: proporciona tiempos constantes $O(1)$ en operaciones básicas (add, remove, contains), siempre que la función hash disperse adecuadamente los elementos.
    • No garantiza ningún orden en los elementos ni al iterar sobre ellos; el orden puede cambiar con el tiempo al insertar nuevos elementos.
    • Es la opción más empleada cuando la prioridad es la velocidad y el orden no es relevante.
    • Permite definir capacidad inicial y factor de carga para optimizar el rendimiento.

    5.1.2. TreeSet

    • Almacena los elementos en una estructura en árbol (árbol rojo-negro autobalanceado).
    • Mantiene siempre sus elementos ordenados en función de sus valores:
    • Mediante el orden natural de los objetos (que deben implementar la interfaz Comparable).
    • O mediante un Comparator personalizado suministrado en el constructor.
    • Es más lento que HashSet: garantiza un tiempo de ejecución de $O(\log N)$ en las operaciones básicas.

    5.1.3. LinkedHashSet

    • Almacena los elementos en una tabla hash combinada con una lista doblemente enlazada que une todas las entradas.
    • Mantiene los elementos en el orden exacto en que fueron insertados.
    • Su coste computacional es ligeramente superior al de HashSet, pero sensiblemente más rápido que TreeSet.
    Implementación Ordenación de los elementos Velocidad Caso de uso principal
    HashSet Sin orden garantizado (usa tabla hash). ⚡ Muy rápida Eliminar duplicados al instante cuando el orden no importa.
    LinkedHashSet Mantiene el orden de inserción. ⚡ Rápida Eliminar duplicados recordando el orden en que se introdujeron.
    TreeSet Orden natural automático (alfabético/numérico). ⚖️ Equilibrada Mantener una colección de valores únicos siempre ordenados.

    import java.util.HashSet;
import java.util.List;
import java.util.Set;
import java.util.TreeSet;

public class EjemploSets {
    public static void main(String[] args) {
        List<String> ciudades = List.of("Valencia", "Alicante", "Castellón", "Valencia", "Alicante");

        // 1. Eliminar duplicados con HashSet (sin orden fijo)
        Set<String> sinDuplicados = new HashSet<>(ciudades);
        System.out.println("HashSet: " + sinDuplicados);

        // 2. Eliminar duplicados y ordenar alfabéticamente con TreeSet
        Set<String> ordenadas = new TreeSet<>(ciudades);
        System.out.println("TreeSet: " + ordenadas);
    }
}

    import java.util.Iterator;
import java.util.LinkedHashSet;
import java.util.Set;

public class LinkedHashSetEjemplo {
    public static void main(String[] args) {
        Set<String> set = new LinkedHashSet<>();
        set.add("Uno");
        set.add("Dos");
        set.add("Tres");
        set.add("Uno"); // Elemento duplicado: será ignorado
        set.add("Cuatro");

        Iterator<String> it = set.iterator();
        while (it.hasNext()) {
            System.out.println(it.next());
        }
        // Salida: Uno -> Dos -> Tres -> Cuatro
    }
}

    Set<String> s1 = new HashSet<>(Set.of("A", "B", "C"));
Set<String> s2 = new HashSet<>(Set.of("B", "C", "D"));

// Unión (s1 U s2): elementos en s1 o en s2
Set<String> union = new HashSet<>(s1);
union.addAll(s2); // ["A", "B", "C", "D"]

// Intersección (s1 ∩ s2): elementos comunes
Set<String> interseccion = new HashSet<>(s1);
interseccion.retainAll(s2); // ["B", "C"]

// Diferencia (s1 \ s2): elementos en s1 que no están en s2
Set<String> diferencia = new HashSet<>(s1);
diferencia.removeAll(s2); // ["A"]
