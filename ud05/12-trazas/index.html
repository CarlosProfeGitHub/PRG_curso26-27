    12. Trazas

    Actividades no obligatorias

    Las trazas tampoco son obligatorias. Guárdalas en ud05/trazas.

    ¿En qué consiste una traza?

    Leer un programa sin ejecutarlo, anotando el valor de cada elemento de la colección en cada instrucción. En esta unidad lo que más se complica es el estado de la colección y el iterador al mismo tiempo.

    El método

    1. Escribe la colección con su contenido inicial.
    2. Para cada operación, anota el contenido tras la instrucción.
    3. Si usas un iterador, anota también la posición del cursor.
    4. Marca qué elemento estás mirando: los errores de recorrido vienen de mirar el elemento equivocado.

    Traza 01 · add, set y remove

    1

    List<String> lista = new ArrayList<>();
lista.add("A");
lista.add("B");
lista.add("C");
lista.add(1, "X");
lista.set(2, "Y");
lista.remove("B");
System.out.println(lista);
    Solución 
    [A, X, Y, C]
    Paso Operación Contenido
    Inicial — []
    add("A") añade al final [A]
    add("B") añade al final [A, B]
    add("C") añade al final [A, B, C]
    add(1, "X") inserta en posición 1 [A, X, B, C]
    set(2, "Y") sustituye posición 2 [A, X, Y, C]
    remove("B") elimina "B" (ya no está) sin cambio → [A, X, Y, C]

    Traza 02 · El Iterator que elimina

    1
2
3
4
5
6
7
8
9
    List<Integer> lista = new ArrayList<>(List.of(1, 2, 3, 4, 5));
Iterator<Integer> it = lista.iterator();
while (it.hasNext()) {
    int n = it.next();
    if (n % 2 == 0) {
        it.remove();
    }
}
System.out.println(lista);
    Solución 
    [1, 3, 5]
    Vuelta n Acción Contenido tras la vuelta
    1.ª 1 no elimina [1, 2, 3, 4, 5]
    2.ª 2 elimina [1, 3, 4, 5]
    3.ª 3 no elimina [1, 3, 4, 5]
    4.ª 4 elimina [1, 3, 5]
    5.ª 5 no elimina [1, 3, 5]

    El iterador avanza solo

    Tras it.remove(), el iterador ya apunta al siguiente elemento. No llames a it.next() otra vez en la misma vuelta.

    Traza 03 · HashSet vs TreeSet

    1
2
3
4
5
    List<String> ciudades = List.of("Valencia", "Alicante", "Castellón", "Valencia");
Set<String> hs = new HashSet<>(ciudades);
Set<String> ts = new TreeSet<>(ciudades);
System.out.println("HashSet: " + hs);
System.out.println("TreeSet: " + ts);
    Solución 
    HashSet: [Valencia, Castellón, Alicante]   (orden no garantizado)
TreeSet: [Alicante, Castellón, Valencia]   (orden alfabético)

    El HashSet elimina el duplicado de "Valencia" pero no garantiza orden. El TreeSet elimina el duplicado y ordena alfabéticamente.

    Traza 04 · HashMap y getOrDefault

    1
2
3
4
5
6
7
8
    Map<String, Integer> mapa = new HashMap<>();
mapa.put("Ana", 5);
mapa.put("Luis", 7);
mapa.put("Ana", 9);          // Sobrescribe
int a = mapa.get("Ana");
int b = mapa.getOrDefault("Pedro", 0);
System.out.println(a + " " + b);
System.out.println(mapa.size());
    Solución 
    9 0
2
    • put("Ana", 9) sobrescribe el valor anterior y devuelve 5 (que se ignora).
    • get("Ana") devuelve 9.
    • getOrDefault("Pedro", 0) devuelve 0 porque "Pedro" no existe.
    • size() es 2: "Ana" y "Luis".

    Queue<Integer> pq = new PriorityQueue<>();
pq.offer(30);
pq.offer(10);
pq.offer(20);
while (!pq.isEmpty()) {
    System.out.print(pq.poll() + " ");
}
    Solución 
    10 20 30

    Una PriorityQueue de enteros ordena por orden natural ascendente: el menor siempre sale primero.

    Traza 06 · removeIf

    1
2
3
    List<Integer> lista = new ArrayList<>(List.of(1, 2, 3, 4, 5, 6));
lista.removeIf(n -> n % 2 == 0);
System.out.println(lista);
    Solución 
    [1, 3, 5]

    removeIf elimina todos los elementos pares en una sola operación. Equivale a recorrer con un Iterator y llamar a remove().
