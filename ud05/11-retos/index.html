    11. Retos opcionales

    Actividades no obligatorias

    Los retos no son obligatorios, pero son la mejor forma de consolidar lo aprendido antes de UD06. Guárdalos en ud05/retos.

    Reto 01 · Eliminar duplicados manteniendo el orden

    Escribe static List<String> sinDuplicados(List<String> datos) que devuelva una lista sin valores repetidos, manteniendo el orden original.

    Entrada: [Valencia, Alicante, Valencia, Castellón, Alicante]
Salida:  [Valencia, Alicante, Castellón]

    Sin usar un Set

    Un doble bucle sirve: para cada posición, comprueba que no haya aparecido antes.

    boolean repetido = false;
for (int j = 0; j < i; j++) {
    if (datos.get(j).equals(datos.get(i))) {
        repetido = true;
    }
}

    Después resuelve el mismo problema usando un LinkedHashSet y compara la legibilidad.

    Reto 02 · Rotar una lista

    Escribe static void rotar(List<Integer> datos, int posiciones) que mueva los elementos posiciones plazas hacia la derecha, dando la vuelta al final.

    Original:  [1, 2, 3, 4, 5]
Rotar 2:   [4, 5, 1, 2, 3]

    Hazlo con un array auxiliar y luego con Collections.rotate(). Explica cuál te parece más legible.

    Reto 03 · Mezclar dos listas ordenadas

    Escribe static List<Integer> mezclar(List<Integer> a, List<Integer> b) que devuelva un solo ArrayList ordenado con todos los elementos de las dos listas de entrada (las dos deben estar ordenadas).

    a = [1, 4, 7]
b = [2, 3, 8]
→ [1, 2, 3, 4, 7, 8]

    Sin concatenar y ordenar

    Si concatenaras y usaras Collections.sort(), el ejercicio sería trivial. El objetivo es hacerlo con dos índices, avanzando en las dos listas a la vez.

    Reto 04 · Frecuencias con un Map

    Escribe static Map<Integer, Integer> frecuencias(List<Integer> datos) que devuelva, para cada valor del 0 al 9, cuántas veces aparece.

    Entrada: [1, 3, 1, 7, 3, 3, 0]
Salida:  {0=1, 1=2, 3=3, 7=1}

    Usa getOrDefault

    mapa.put(valor, mapa.getOrDefault(valor, 0) + 1);

    Reto 05 · Invertir un mapa

    Escribe static Map<V, K> invertir(Map<K, V> mapa) que devuelva un mapa con claves y valores intercambiados.

    ¿Y si hay valores duplicados?

    Si dos claves comparten el mismo valor, al invertir se perderá una. Decide cómo resolverlo (por ejemplo, usando Map<V, List<K>>) y justifícalo.

    Reto 06 · El más frecuente

    Dada una lista de palabras, devuelve la palabra que aparece más veces. Si hay empate, devuelve cualquiera de ellas.

    Reto 07 · Historial con deshacer

    Simula un editor de texto con dos pilas: una para el texto actual y otra para el historial de acciones. Implementa:

    • escribir(String texto)
    • borrar()
    • deshacer()

    Reto 08 · Cola de prioridad de tareas

    Crea una PriorityQueue<Tarea> donde cada Tarea tenga un nombre y una prioridad (1 = urgente, 5 = baja). Procesa las tareas en orden de prioridad.

    Reto 09 · Conjunto de palabras únicas

    Lee un texto y devuelve el conjunto de palabras únicas ordenadas alfabéticamente. Ignora mayúsculas/minúsculas y signos de puntuación.

    Reto 10 · Mapa de sinónimos completo

    Amplía la Actividad 25 para que el diccionario se guarde en un fichero y se cargue al iniciar el programa. (Pista: esto se verá en la UD09.)
