    6. Pilas y colas

    Las estructuras de datos de tipo Cola y Pila organizan los elementos según estrictas políticas de acceso y extracción:

    • Cola (Queue): política FIFO (First In, First Out) — el primero en llegar es el primero en salir.
    • Pila (Stack): política LIFO (Last In, First Out) — el último en llegar es el primero en salir.

    6.1. Colas (Queue<E>)

    Una cola modela situaciones de la vida real como la cola de una taquilla, una parada de autobús o la cola de impresión de un servidor de red.

    • Los elementos se insertan por la parte posterior (rear / enqueue) y se extraen por el frente (front / dequeue).

    Métodos de Queue<E>

    En la interfaz Queue, cada operación básica dispone de dos variantes: una que lanza una excepción si la operación falla y otra que devuelve un valor especial (false o null):

    Operación Lanza excepción si falla Retorna valor especial (false / null)
    Insertar al final add(e) offer(e)
    Eliminar y obtener el frente remove() poll()
    Consultar el frente sin borrar element() peek()

    Además, hereda todos los métodos comunes de Collection: size(), isEmpty(), clear(), etc.

    PriorityQueue (Cola de prioridad)

    Una cola de prioridad es un tipo especial de cola donde los elementos no se procesan por orden cronológico de llegada, sino según su orden de prioridad:

    • Se ordenan según su orden natural (Comparable) o mediante un comparador (Comparator).
    • La cabeza de la cola contiene en todo momento el menor elemento (según el criterio de ordenación establecido).

    import java.util.LinkedList;
import java.util.PriorityQueue;
import java.util.Queue;

public class EjemploColas {
    public static void main(String[] args) {
        // 1. Cola FIFO estándar usando LinkedList
        Queue<String> colaEspera = new LinkedList<>();
        colaEspera.offer("Cliente 1");
        colaEspera.offer("Cliente 2");
        colaEspera.offer("Cliente 3");

        System.out.println("Atendiendo a: " + colaEspera.poll());   // Cliente 1
        System.out.println("Próximo en cola: " + colaEspera.peek()); // Cliente 2

        // 2. Cola de prioridad (orden natural ascendente)
        Queue<Integer> colaPrioridad = new PriorityQueue<>();
        colaPrioridad.offer(900);
        colaPrioridad.offer(100);
        colaPrioridad.offer(500);

        System.out.print("Salida de PriorityQueue: ");
        while (!colaPrioridad.isEmpty()) {
            System.out.print(colaPrioridad.poll() + " "); // 100 500 900
        }
    }
}

    6.2. Pilas (Stack<E>)

    Una pila modela el comportamiento de una pila de platos o la pila de llamadas a funciones (call stack): colocamos un plato sobre el anterior y solo podemos retirar el que está en la cima (top).

    • Inserción (push): añade un elemento en la cima de la pila.
    • Extracción (pop): retira y devuelve el elemento situado en la cima.

    Métodos de Stack<E>

    Método Descripción
    E push(E item) Inserta un elemento en la cima de la pila y lo devuelve.
    E pop() Elimina y devuelve el elemento de la cima de la pila (lanza EmptyStackException si está vacía).
    E peek() Consulta el elemento de la cima sin eliminarlo de la pila.
    boolean empty() Devuelve true si la pila no contiene elementos (o isEmpty()).
    int search(Object o) Devuelve la distancia desde la cima en base 1 hasta el objeto, o -1 si no existe.

    import java.util.Stack;

public class EjemploPila {
    public static void main(String[] args) {
        Stack<String> historial = new Stack<>();
        historial.push("google.es");
        historial.push("github.com");
        historial.push("stackoverflow.com");

        System.out.println("Página actual (cima): " + historial.peek()); // stackoverflow.com

        while (!historial.empty()) {
            System.out.println("Desapilando: " + historial.pop());
        }
    }
}

    6.3. Recomendación en Java moderno: Deque y ArrayDeque

    La clase Stack es una clase legada (histórica). Forma parte de Java 1.0 y hereda directamente de Vector, lo que implica que sus métodos están sincronizados y penalizan innecesariamente el rendimiento en aplicaciones monohilo.

    La propia documentación oficial de Oracle recomienda utilizar la interfaz Deque (Double Ended Queue) implementada mediante ArrayDeque cuando se necesite una pila o una cola en proyectos modernos:

    import java.util.ArrayDeque;
import java.util.Deque;

public class EjemploPilaModerna {
    public static void main(String[] args) {
        // Uso de Deque como pila moderna (LIFO)
        Deque<String> pilaModerna = new ArrayDeque<>();
        pilaModerna.push("Página 1");
        pilaModerna.push("Página 2");
        pilaModerna.push("Página 3");

        System.out.println("Cima: " + pilaModerna.peek()); // Página 3

        while (!pilaModerna.isEmpty()) {
            System.out.println("Extraído: " + pilaModerna.pop());
        }
    }
}

    Resumen de elección

    • Cola FIFO: Queue<String> cola = new LinkedList<>(); o new ArrayDeque<>();
    • Cola de prioridad: Queue<Integer> pq = new PriorityQueue<>();
    • Pila moderna: Deque<String> pila = new ArrayDeque<>();
    • Pila legada: Stack<String> pila = new Stack<>(); (solo por compatibilidad)
