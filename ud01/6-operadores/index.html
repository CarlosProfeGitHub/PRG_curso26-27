    6. Operadores y expresiones

    6.1. Operadores aritméticos

    Operador Uso Operación a=8, b=5
    + A + B Suma 13
    - A - B Resta 3
    * A * B Multiplicación 40
    / A / B División 1 (entera) / 1.6 (real)
    % A % B Módulo o resto 3

    La trampa de la división entera

    Si ambos operandos son enteros, el resultado es entero y se pierde la parte decimal:

    int a = 8, b = 5;
System.out.println(a / b);      // 1  (¡no 1.6!)
System.out.println((double) a / b);  // 1.6 (con conversión explícita)
System.out.println(a / (double) b);  // 1.6
System.out.println(a / 5.0);     // 1.6 (porque 5.0 es double)

    Esta es probablemente la fuente de errores nº1 de la unidad. Usa double o una conversión explícita.

    6.2. Operadores relacionales

    Devuelven un boolean (true o false):

    Operador Uso Significado valor1=10, valor2=3
    < A < B A menor que B false
    > A > B A mayor que B true
    <= A <= B A menor o igual que B false
    >= A >= B A mayor o igual que B true
    != A != B A distinto de B true
    == A == B A igual a B false

    6.3. Operadores lógicos

    Operador Nombre Operación
    && o & AND true solo si ambos operandos son true.
    \|\| o \| OR false solo si ambos operandos son false.
    ! NOT Invierte el valor de verdad.
    ^ XOR true si exactamente uno de los operandos es true.

    Tablas de verdad (conviene memorizarlas):

    A B A && B A \|\| B !A A ^ B
    false false false false true false
    true false false true false true
    false true false true true true
    true true true true false false

    ¿& o &&? ¿| o ||?

    Aunque producen el mismo resultado lógico, hay una diferencia clave en cómo los evalúa Java:

    Operador Nombre Comportamiento
    && AND cortocircuito Si el primer operando es false, Java no evalúa el segundo.
    & AND bit a bit Siempre evalúa los dos operandos.
    \|\| OR cortocircuito Si el primer operando es true, Java no evalúa el segundo.
    \| OR bit a bit Siempre evalúa los dos operandos.

    ¿Por qué importa? Con && y || el programa es más eficiente y evita errores:

    1

    int[] numeros = null;

// Con &  → ERROR: evalúa ambos lados aunque numeros sea null
if (numeros != null & numeros.length > 0) { }

// Con && → SEGURO: si numeros es null, no llega a mirar .length
if (numeros != null && numeros.length > 0) {
}

    Regla práctica: usa siempre && y || para condiciones lógicas. Reserva & y | solo para operaciones a nivel de bits.

    6.4. Operadores unarios o unitarios

    Operador Uso Operación
    ++ A++ o ++A Incremento de A
    -- A-- o --A Decremento de A

    Prefijo (++A) frente a sufijo (A++)

    La posición del operador cambia cuándo se aplica el incremento:

    • Prefijo (++A) → primero incrementa, luego usa el nuevo valor.
    • Sufijo (A++) → primero usa el valor actual, luego incrementa.

    int A = 1, B;

// Prefijo
B = ++A;
// Paso 1: A se incrementa → A vale 2
// Paso 2: B recibe el valor de A → B vale 2
// Resultado: A=2, B=2

// Sufijo
B = A++;
// Paso 1: B recibe el valor ACTUAL de A → B vale 2
// Paso 2: A se incrementa → A vale 3
// Resultado: A=3, B=2

    6.6. Operador condicional ?:

    Único operador ternario de Java. Evalúa una condición y devuelve un resultado en función de si es verdadera o falsa. Necesita tres operandos:

    • Condición (a la izquierda de ?): expresión booleana.
    • Exp1 (entre ? y :): valor si la condición es verdadera.
    • Exp2 (después de :): valor si la condición es falsa.
    condición ? exp1 : exp2

    1
2
    int mayor, exp1 = 15, exp2 = 25;
mayor = (exp1 > exp2) ? exp1 : exp2;   // mayor valdrá 25

    El operador condicional se puede sustituir por la sentencia if...else, que veremos más adelante.

    6.7. Prevalencia de operadores

    Los operadores tienen diferente prioridad. Es interesante utilizar paréntesis para controlar las operaciones sin depender de la prevalencia.

    Ordenados de arriba a abajo, de más a menos prioridad:

    Descripción Operadores
    Operadores postfijos op++ op--
    Operadores unarios ++op --op +op -op ~ !
    Multiplicación y división * / %
    Suma y resta + -
    Desplazamiento << >> >>>
    Operadores relacionales < > <= >=
    Equivalencia == !=
    Operador AND &
    Operador XOR ^
    Operador OR \|
    AND booleano &&
    OR booleano \|\|
    Condicional ?:
    Asignación = += -= *= /= %=

    6.8. Operadores de bits y desplazamientos

    Estos operadores trabajan con la representación binaria de los enteros:

    int q = 132;   // q: 00000000000000000000000010000100
int r = 144;   // r: 00000000000000000000000010010000
int s = q & r; // s: 00000000000000000000000010000000 → 128
int t = q | r; // t: 00000000000000000000000010010100 → 148
int u = q ^ r; // u: 00000000000000000000000000010100 → 20
int v = ~q;    // v: 11111111111111111111111101111011 → -133

int j = 33;
int k = j << 2;  // 00000000000000000000000010000100 → 132
int o = 132;
int p = o >> 2;  // 00000000000000000000000000100001 → 33
int x = -1;
int y = x >>> 2; // 00111111111111111111111111111111 → 1073741823
    Operador Nombre Efecto
    << Desplazamiento a la izquierda Multiplica por 2ⁿ
    >> Desplazamiento a la derecha (con signo) Divide entre 2ⁿ (conserva el signo)
    >>> Desplazamiento a la derecha sin signo Rellena con ceros a la izquierda
    & AND bit a bit 1 solo si ambos bits son 1
    \| OR bit a bit 1 si alguno de los bits es 1
    ^ XOR bit a bit 1 si los bits son distintos
    ~ Complemento Invierte todos los bits

    Para qué sirve esto en 1º DAM

    Los desplazamientos de bits son la base del cálculo de máscaras de red y subredes que verás en el módulo de redes, y de muchas optimizaciones internas del lenguaje.
