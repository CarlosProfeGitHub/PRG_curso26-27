    ¿En qué consiste una traza?

    Consiste en leer un programa sin ejecutarlo, anotando el valor de cada variable en cada instrucción hasta llegar al final. Es la habilidad más transferible de la programación y la que más rápido detecta errores.

    public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int x, y, a;

    x = sc.nextInt();
    y = sc.nextInt();
    a = x;
    doble(a);             // ¡el resultado se descarta!

}

public static void doble(int x) {
    x = 2 * x;
}
    Solución 
    2
5
2

    En Java los parámetros se pasan por valor: dentro de doble se modifica una copia de a. Fuera del método, a sigue valiendo 2. Este es un concepto clave que veremos en profundidad en UD06.

    public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int x, y, a;

    x = sc.nextInt();
    y = sc.nextInt();
    a = calcular(y, x);    // ¡parámetros en otro orden!

    System.out.printf("%d%n%d%n%d", x, y, a);
}

public static int calcular(int x, int y) {
    return x - y;
}
    Solución 
    2
5
-3

    calcular(y, x) recibe x_param = 5 e y_param = 2, y devuelve 5 - 2… ¡no! Cuidado: return x - y con x_param = 5, y_param = 2 devuelve 3.

    Corrección: los parámetros se asignan en orden, así que dentro del método x = 5 e y = 2, y x - y = 5 - 2 = 3.

    public static void main(String[] args) {
    Scanner sc = new Scanner(System.in);
    int x, y, a;

    x = sc.nextInt();
    y = sc.nextInt();
    y = calcular(x);      // y = x²
    a = calcular(y);      // a = y²

    System.out.printf("%d%n%d%n%d", x, y, a);
}

public static int calcular(int x) {
    return x * x;
}
    Solución

    Con x = 2:

    • y = calcular(2) = 2 * 2 = 4
    • a = calcular(4) = 4 * 4 = 16
