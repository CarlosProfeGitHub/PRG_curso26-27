    Actividad 02 · Expresiones en sintaxis de Java

    Escribe las siguientes expresiones usando la sintaxis de Java. Si alguna necesita paréntesis, añade una nota explicando por qué.

    1. El doble de A más el triple de B.
    2. La mitad del cuadrado de la suma de A y B.
    3. El porcentaje que representa B respecto a A.
    4. Si A es mayor que B y, además, B es menor que C.
    5. El área de un círculo de radio R: π · R².
    6. El promedio entre el cuadrado de A y el cuadrado de B.
    Solución orientativa 
    // 1
2 * A + 3 * B

// 2
Math.pow(A + B, 2) / 2

// 3
(B * 100) / A + "%"

// 4
A > B && B < C

// 5
Math.PI * Math.pow(R, 2)

// 6
(Math.pow(A, 2) + Math.pow(B, 2)) / 2

    Actividad 04 · Expresiones lógicas y relacionales

    Sean 4 variables enteras que contienen la edad de cuatro personas:

    int m, j, p, v;
// m = Miguel, j = Julio, p = Pablo, v = Vicente

    Expresa las siguientes afirmaciones usando operadores lógicos y relacionales. Ejemplo resuelto:

    Miguel es mayor de edad. → m >= 18

    1. Miguel es menor de edad.
    2. Miguel es mayor que Julio.
    3. Miguel es el más viejo.
    4. Miguel es el más joven.
    5. Miguel no es el más joven.
    6. Alguno de ellos es mayor de edad.
    7. Miguel y Julio son los más jóvenes.
    8. Entre todos tienen más de 100 años.
    9. Entre Miguel y Julio suman más edad que Pablo.
    10. Al menos uno de ellos es menor de edad.
    11. Al menos dos de ellos son menores de edad.
    12. Todos son menores de edad.
    13. Solo dos de ellos son menores de edad.
    14. Al menos dos de ellos nacieron el mismo año.
    15. Solo uno de ellos es menor que Julio.
    Pista para la 14 y la 15

    "Al menos dos de ellos…" es una disyunción (||) de conjunciones (&&).

    // Al menos dos de los cuatro tienen menos de 18 años
(m < 18 && j < 18) || (m < 18 && p < 18) || (m < 18 && v < 18)
    || (j < 18 && p < 18) || (j < 18 && v < 18) || (p < 18 && v < 18)

    Actividad 06 · Predice la salida

    Indica qué valor imprimirá el siguiente programa y por qué:

    1
2
3
4
5
6
7
    public class Actividad06 {
    public static void main(String[] args) {
        int num = 5;
        num += num - 1 * 4 + 1;
        System.out.println(num);
    }
}
    Solución

    Se imprime 2.

    Paso a paso: 1 * 4 vale 4 → num - 4 + 1 = 5 - 4 + 1 = 2 → num += 2 → num = 5 + 2 = 7.

    Cuidado: el += usa el valor original de num (5), no el resultado intermedio del paréntesis derecho una vez reevaluado.

    Actividad 07 · Precedencia y módulo

    Indica qué valor imprimirá el siguiente programa:

    1
2
3
4
5
6
7
    public class Actividad07 {
    public static void main(String[] args) {
        int num = 4;
        num %= 7 * num % 3 * 3;
        System.out.println(num);
    }
}
    Solución

    Se imprime 0.

    * y % tienen la misma prioridad y se evalúan de izquierda a derecha: 7 * 4 = 28 → 28 % 3 = 1 → 1 * 3 = 3 → num %= 3 → 4 % 3 = 1.

    Escribe los pasos en papel antes de ejecutar el programa: es la única forma de saber si tu traza es correcta.

    Experimenta qué pasa si en el siguiente programa inicializas realLlarg con un valor con varios decimales. ¿El programa continúa compilando? ¿Qué resultado da?

    Después inténtalo asignando un valor superior al rango de los enteros (por ejemplo, 3000000000.0).

    public class ConversionExplicita {
    public static void main(String[] args) {
        double realLlarg = 300.0;

        // Asignación incorrecta. ¿Un real tiene decimales, no?
        long enterLlarg = (long) realLlarg;

        // Asignación incorrecta. ¿Un entero largo tiene un rango mayor que un entero, no?
        int enter = (int) enterLlarg;

        System.out.println(enter);
    }
}
    Qué debes observar
    1. Si asignas 300.7, el programa compila pero (long) realLlarg trunca y da 300: se pierde el decimal.
    2. Si asignas 3000000000.0, el programa NO compila: ese valor no cabe en un long ni en un int. Necesitarías un double (o long) y quitar el cast a int.

    Actividad 26 · Redondear a un decimal

    Math.round(x) redondea x de manera que queda sin decimales (Math.round(35.5289) da como resultado 36).

    Escribe un programa en el que el usuario introduzca un número real y se muestre redondeado a un solo decimal.

    Pista: combinar productos, divisiones y Math.round()

    Introduce un número real: 35.5289
El número 35.5289, redondeado a un decimal es 35.5
    Solución 
    1
2
3
    double numero = 35.5289;
double redondeado = Math.round(numero * 10) / 10.0;
System.out.println(redondeado);   // 35.5

    Multiplicar por 10, redondear, dividir por 10.0. Importante: la división debe ser real (/ 10.0), nunca entera.
