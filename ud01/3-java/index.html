    3. El lenguaje Java

    3.1. ¿Qué es Java?

    Java es un lenguaje sencillo de aprender, con sintaxis parecida a la de C++, pero en la que se han eliminado elementos complicados que originan errores. Es un lenguaje orientado a objetos, lo que permite usar gran cantidad de bibliotecas ya definidas y evitar reescribir código existente.

    Su principal virtud es la independencia del hardware: el código generado es válido para cualquier plataforma porque se ejecuta sobre una Máquina Virtual Java (JVM), que traduce el bytecode al código específico de cada sistema. De ahí su lema: "Write once, run everywhere".

    Características principales:

    # Característica Significado práctico
    1 Código independiente de la arquitectura El mismo .class funciona en Windows, Linux o macOS.
    2 Totalmente orientado a objetos Todo es clase y objeto (loPumpemos en UD06).
    3 Sintaxis similar a C y C++ Facilita la transición desde otros lenguajes.
    4 Preparado para aplicaciones TCP/IP Base de la computación distribuida y de red.
    5 Amplio conjunto de bibliotecas Math, Scanner, String… vienen incluidos.
    6 Robusto Comprueba errores en tiempo de compilación y de ejecución.
    7 Seguro El acceso a memoria y sistema está controlado por la JVM.

    Historia mínima para el examen

    Antes de Java, el lenguaje C era uno de los más extendidos por su versatilidad, pero al crecer el volumen de los programas su manejo se complicaba. La programación estructurada y modular no bastaba. Entonces llegó la Programación Orientada a Objetos (POO), que aproxima la construcción de programas al pensamiento humano: los problemas se dividen en objetos que tienen propiedades e interactúan entre sí.

    3.2. Estructura y bloques fundamentales

    En Java toda instrucción ejecutable se organiza en clases y métodos. El punto de entrada de cualquier aplicación es el método main.

    // Punto de entrada: el método main es lo primero que ejecuta la JVM

    Elemento Descripción
    Clase (public class HolaMundo) El nombre de la clase pública debe coincidir exactamente con el nombre del archivo (HolaMundo.java).
    Método main Punto de inicio obligatorio de cualquier aplicación Java estándar.
    Instrucción Toda sentencia termina obligatoriamente en ; (punto y coma).
    Bloque { … } Agrupa instrucciones; define el ámbito de las variables.
    static Indica que el método pertenece a la clase, no a sus instancias.
    void El método no devuelve ningún valor.
    String[] args Vector de parámetros que recibe el sistema operativo.

    Sangrado o indentación

    La indentación consiste en dejar una sangría en el margen izquierdo de cada línea dentro de un bloque { ... }. No es obligatoria para el compilador, pero mejora drásticamente la lectura del código.

    • Se recomienda usar entre 2 y 4 espacios (o un tabulador).
    • Limita el ancho de las líneas a unos 70-90 caracteres para que quepan en cualquier pantalla sin scroll horizontal.

    3.3. Compilar y ejecutar un programa Java

    Todo programa pasa por tres fases:

    1. Código fuente (.java)
        │  javac HolaMundo.java
        ▼
2. Bytecode (.class)
        │  java HolaMundo
        ▼
3. Ejecución en la JVM → salida por consola

    Paso 1 · Creación del código fuente

    Escribes el código en un editor y lo guardas como HolaMundo.java. Recuerda la ruta donde lo has guardado.

    Paso 2 · Compilación

    javac HolaMundo.java

    El compilador javac (java compiler) transforma tu código en el lenguaje de la máquina virtual Java (bytecode), generando un archivo HolaMundo.class en el mismo directorio. Si no aparecen errores, ya tienes ambos archivos.

    Comprueba tu instalación

    javac --version
java --version

    Debe mostrar javac 21.x.x (o similar). Si el comando no se reconoce, revisa el UD00 · Configura tu entorno o reinstala el JDK 21.

    Paso 3 · Ejecución

    java HolaMundo

    Fíjate bien

    • javac con la c = compilar.
    • java sin la c = ejecutar.
    • En java HolaMundo no pones la extensión .class.

    Error más común al empezar

    'javac' no se reconoce como un comando interno o externo…

    Significa que el JDK no está instalado o que la variable de entorno JAVA_HOME / el PATH no están configurados. Repasa la configuración del entorno en UD00.
