    10. Clases envoltorio

    10.1. De tipos primitivos a clases envoltorio (Wrappers)

    En Java existen dos grandes categorías de tipos de datos:

    1. Tipos primitivos (int, double, char, boolean…): almacenan directamente el valor en la pila. Son eficientes, pero no son objetos: no tienen métodos.
    2. Tipos referenciados (clases): almacenan una referencia a un objeto en el heap y disponen de métodos de utilidad.

    Para salvar esta limitación, Java incluye en java.lang (disponible sin import) una clase envoltorio (wrapper) para cada uno de los 8 primitivos:

    Primitivo Wrapper Ejemplo de método estático útil
    byte Byte Byte.parseByte("10")
    short Short Short.MAX_VALUE
    int Integer Integer.parseInt("42")
    long Long Long.parseLong("10000000000")
    float Float Float.parseFloat("3.14F")
    double Double Double.parseDouble("19.99")
    char Character Character.isDigit('7')
    boolean Boolean Boolean.parseBoolean("true")

    Autoboxing y unboxing

    Java convierte automáticamente entre el primitivo y su wrapper:

    Integer numObjeto = 10;        // autoboxing
int numPrimitivo = numObjeto;  // unboxing

    Desde Java 9, los constructores como new Integer(10) están obsoletos (deprecated).

    10.2. La clase Character: inspección y validación de caracteres

    El tipo char solo almacena un carácter. Al ser primitivo, no dispone de métodos propios. Para saber si un carácter es letra, dígito, espacio o signo usamos los métodos estáticos de Character.

    10.2.1. Métodos de comprobación booleana (is…)

    Método Devuelve Descripción
    Character.isDigit(c) boolean Dígito numérico ('0'–'9')
    Character.isLetter(c) boolean Letra alfabética (incluye tildes, ñ, Unicode)
    Character.isLetterOrDigit(c) boolean Alfanumérico
    Character.isWhitespace(c) boolean Espacio, tabulador o salto de línea
    Character.isUpperCase(c) boolean Mayúscula
    Character.isLowerCase(c) boolean Minúscula

    10.2.2. Métodos de transformación (to…)

    Método Devuelve Descripción
    Character.toUpperCase(c) char Convierte a mayúscula
    Character.toLowerCase(c) char Convierte a minúscula

    import java.util.Scanner;

public class ClasificadorCaracter {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Introduce un solo carácter: ");
        char entrada = sc.next().charAt(0);

        if (Character.isDigit(entrada)) {
            System.out.println("Es un DÍGITO NUMÉRICO.");
        } else if (Character.isLetter(entrada)) {
            System.out.println("Es una LETRA ALFABÉTICA.");
            char opuesto = Character.isUpperCase(entrada)
                    ? Character.toLowerCase(entrada)
                    : Character.toUpperCase(entrada);
            System.out.println("Su opuesto es: " + opuesto);
        } else if (Character.isWhitespace(entrada)) {
            System.out.println("Es un espacio en blanco.");
        } else {
            System.out.println("Es un SÍMBOLO o signo de puntuación.");
        }
        sc.close();
    }
}

    10.3. Clases numéricas (Integer, Double): conversión y constantes

    Los datos leídos del teclado suelen recibirse como String. Las clases numéricas aportan las funciones de conversión (parsing).

    10.3.1. Conversión de texto (String) a número primitivo

String textoPrecio = "49.95";
double precio = Double.parseDouble(textoPrecio);

    Error común: NumberFormatException

    Si la cadena no contiene un formato numérico válido (por ejemplo, Integer.parseInt("hola") o Integer.parseInt("12.5")), Java lanza NumberFormatException y detiene el programa.

    10.4. La clase String: métodos esenciales de inspección y manipulación

    String representa secuencias alfanuméricas inmutables.

    10.4.1. Métodos fundamentales de consulta

    Método Devuelve Descripción
    s.length() int Número total de caracteres
    s.charAt(i) char Carácter en el índice i (base 0)
    s.isEmpty() boolean true si la longitud es 0
    s.isBlank() boolean true si está vacía o solo espacios

    El puente entre String y Character

    Gracias a s.charAt(i) se puede extraer cualquier carácter para examinarlo con Character:

    String matricula = "4589LKT";
char primerCaracter = matricula.charAt(0);        // '4'
boolean esNumero = Character.isDigit(primerCaracter); // true

    10.4.2. Métodos de comparación (¡regla de oro: nunca usar ==!)

    Los objetos no se comparan con == (compararía direcciones de memoria). Usar siempre los métodos de la clase:

    Método Devuelve Descripción
    s1.equals(s2) boolean Idénticas respetando mayúsculas/minúsculas
    s1.equalsIgnoreCase(s2) boolean Coinciden ignorando mayúsculas/minúsculas
    s1.compareTo(s2) int Comparación lexicográfica: 0 iguales, <0 si s1 va antes, >0 si va después

    10.4.3. Búsqueda y subcadenas

    Método Devuelve Descripción
    s.contains(texto) boolean Si la subcadena está contenida
    s.startsWith(prefijo) boolean Si empieza por el prefijo
    s.endsWith(sufijo) boolean Si termina por el sufijo
    s.indexOf(texto) int Posición de la primera coincidencia (o -1)
    s.substring(inicio) String Desde inicio hasta el final
    s.substring(inicio, fin) String Desde inicio (incluido) hasta fin (excluido)

    10.4.4. Limpieza y transformación de cadenas

    Método Devuelve Descripción
    s.trim() String Elimina espacios laterales
    s.toUpperCase() String Todo a mayúsculas
    s.toLowerCase() String Todo a minúsculas

    Inmutabilidad y encadenamiento

    Los métodos de String no modifican la cadena original, sino que devuelven un nuevo String. Esto permite encadenar llamadas:

    String entradaLimpia = sc.nextLine().trim().toUpperCase();

    import java.util.Scanner;

public class ValidadorDniSimple {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Introduce tu DNI/NIF completo (ej. 12345678Z): ");
        String dni = sc.nextLine().trim().toUpperCase();

        if (dni.length() != 9) {
            System.out.println("Error: el DNI debe tener exactamente 9 caracteres.");
        } else {
            String parteNumerica = dni.substring(0, 8);
            char letraFinal = dni.charAt(8);

            if (!Character.isLetter(letraFinal)) {
                System.out.println("Error: el último carácter debe ser una letra.");
            } else {
                int numeroDni = Integer.parseInt(parteNumerica);
                System.out.println("Formato válido. Número: " + numeroDni + " | Letra: " + letraFinal);
            }
        }
        sc.close();
    }
}

    import java.util.Scanner;

public class ValidadorPassword {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Introduce tu nueva contraseña: ");
        String password = sc.nextLine();

        if (password.length() < 8) {
            System.out.println("Contraseña demasiado corta (mínimo 8 caracteres).");
        } else {
            boolean tieneNumero = false;
            boolean tieneMayuscula = false;
            boolean tieneMinuscula = false;

            for (int i = 0; i < password.length(); i++) {
                char actual = password.charAt(i);
                if (Character.isDigit(actual)) {
                    tieneNumero = true;
                } else if (Character.isUpperCase(actual)) {
                    tieneMayuscula = true;
                } else if (Character.isLowerCase(actual)) {
                    tieneMinuscula = true;
                }
            }

            if (tieneNumero && tieneMayuscula && tieneMinuscula) {
                System.out.println("Contraseña FUERTE y válida.");
            } else {
                System.out.println("Contraseña DÉBIL. Debe incluir al menos:");
                if (!tieneNumero)    System.out.println("   - Un número");
                if (!tieneMayuscula) System.out.println("   - Una letra mayúscula");
                if (!tieneMinuscula) System.out.println("   - Una letra minúscula");
            }
        }
        sc.close();
    }
}

    10.6. Actividades propuestas

    Empaquetar actividades

    Empaqueta las actividades dentro de la carpeta ut02/wrappers_string.

    Actividad 1 · DetectorMatricula

    Escribe un programa que solicite una matrícula en formato español (4 números + 3 letras, ej. 4821KLP):

    1. Limpia los espacios laterales y convierte a mayúsculas.
    2. Comprueba que la longitud sea exactamente 7.
    3. Comprueba que los 4 primeros caracteres sean dígitos (Character.isDigit).
    4. Comprueba que los 3 últimos sean letras (Character.isLetter).
    5. Si es válida, extrae con substring(0, 4) la parte numérica, conviértela con Integer.parseInt y muestra número y letras por separado.

    Actividad 2 · ContadorVocalesConsonantes

    Diseña un programa que pida una frase y, recorriéndola carácter a carácter con charAt(i):

    1. Cuente las vocales (mayúsculas y minúsculas).
    2. Cuente las consonantes.
    3. Cuente los dígitos (Character.isDigit).
    4. Muestre un resumen estadístico tabulado con System.out.printf.
