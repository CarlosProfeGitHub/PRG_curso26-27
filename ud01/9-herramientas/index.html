    9. Herramientas útiles: Math y Scanner

    9.1. La librería Math

    Java proporciona de forma nativa la clase Math (paquete java.lang, no necesita import) para realizar operaciones matemáticas avanzadas, potencias, raíces, redondeos y números aleatorios.

    Constantes matemáticas

    Constante Valor Significado
    Math.PI 3.141592653589793… Número π
    Math.E 2.718281828459045… Base de los logaritmos naturales (número de Euler) 
    1
2
3
4
    double grados = 180.0;
double radianes = grados * (Math.PI / 180.0);

System.out.println("180 grados son " + radianes + " radianes");

    Métodos matemáticos imprescindibles

    Método Descripción Ejemplo Resultado
    Math.pow(base, exp) Eleva la base al exponente (siempre double) Math.pow(2, 3) 8.0
    Math.sqrt(x) Raíz cuadrada de x Math.sqrt(25) 5.0
    Math.abs(x) Valor absoluto Math.abs(-15) 15
    Math.max(a, b) El mayor de dos valores Math.max(10, 20) 20
    Math.min(a, b) El menor de dos valores Math.min(10, 20) 10
    Math.round(x) Redondea al entero más próximo Math.round(4.6) 5
    Math.floor(x) Redondea hacia abajo Math.floor(4.9) 4.0
    Math.ceil(x) Redondea hacia arriba Math.ceil(4.1) 5.0

    Casting con Math.pow()

    Como Math.pow() devuelve siempre double, si quieres guardar el resultado en un int debes hacer un cast explícito:

    int potencia = (int) Math.pow(2, 3);   // 8

    9.2. Generación de números aleatorios (Math.random())

    El método Math.random() genera un número decimal pseudoaleatorio de tipo double en el rango semiabierto [0.0, 1.0): mayor o igual que 0.0 y estrictamente menor que 1.0.

    1
    double aleatorio = Math.random();          // Ejemplo: 0.73481293847

    Para obtener enteros utilizables:

    1
2
3
4
5
6
7
8
    // Decimal entre 0.0 y 100.0 (excluido el 100)
double decimal0a100 = Math.random() * 100;

// Entero entre 0 y 99
int entero0a99 = (int) (Math.random() * 100);

// Entero entre 1 y 100
int entero1a100 = (int) (Math.random() * 100) + 1;

    Fórmula general para generar un entero en el rango [min, max]

    1
    int numero = (int) (Math.random() * (max - min + 1)) + min;

    1
2
    // Tirada de un dado estándar de 6 caras
int dado = (int) (Math.random() * (6 - 1 + 1)) + 1;   // 1..6

    9.3. La clase Scanner

    La clase Scanner permite leer datos introducidos por el usuario desde el teclado.

    Paso 1 · importar la librería:

    import java.util.Scanner;

    Paso 2 · inicializar una variable de tipo Scanner:

    Scanner sc = new Scanner(System.in);

    Paso 3 · leer y guardar en las variables correspondientes:

    1
2
3
4
5
    int entero = sc.nextInt();
double decimal = sc.nextDouble();   // también vale sc.nextFloat()
String cadena = sc.nextLine();
char letra = sc.next().charAt(0);   // solo la primera letra
boolean booleano = sc.nextBoolean();   // solo admite 'true' o 'false'
    Método Devuelve
    nextInt() Un int
    nextLong() Un long
    nextDouble() Un double
    nextBoolean() Un boolean
    nextLine() Toda la línea como String
    next() El primer.token (palabra) como String

    ¡Atención! Limpieza del búfer tras leer números

    Al utilizar nextInt(), nextDouble() o nextFloat(), el método lee únicamente el valor numérico y deja el salto de línea (Enter) en el búfer.

    Si a continuación usas nextLine(), este recogerá de inmediato ese salto de línea residual y no esperará a que el usuario escriba, provocando fallos o capturando una cadena vacía.

    Solución: coloca un sc.nextLine(); de limpieza después del número y antes de leer el texto.

    1
2
3
    entero = sc.nextInt();
sc.nextLine();               // Limpia el salto de línea pendiente
cadena = sc.nextLine();      // Ahora sí esperará a que el usuario escriba

    9.4. Mostrar datos formateados (printf)

    printf permite mostrar información alineada, con separadores de millares y número fijo de decimales:

    1
2
3
4
5
    System.out.printf("Producto: %s%n", "Teclado");
System.out.printf("Precio: %.2f euros%n", 19.99);      // 19.99
System.out.printf("Unidades: %d%n", 7);
System.out.printf("Disponible: %b%n", true);
System.out.printf("Alineado: %-10s | %10s%n", "izda", "dcha");
    Especificador Significado Ejemplo
    %s Cadena de texto "hola"
    %d Entero decimal 42
    %f Decimal (6 decimales por defecto) 3.140000
    %.2f Decimal con 2 decimales 3.14
    %c Carácter 'a'
    %b Booleano true
    %n Salto de línea (equivalente a \n)
    %% El símbolo % %
