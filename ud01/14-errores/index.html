    14. Errores frecuentes y cómo solucionarlos

    # Mensaje de error Causa Solución
    1 class, public, or interface expected Falta el punto y coma o hay un carácter raro antes de class. Revisa la línea anterior; el error suele manifestarse una línea antes de donde lo indica el compilador.
    2 ';' expected Falta el ; al final de una instrucción. Añádelo. Cada sentencia termina en ;.
    3 class HolaMundo is public, should be declared in a file named HolaMundo.java El nombre del archivo no coincide con el de la clase pública. Renombra el archivo.
    4 variable might not have been initialized Variable local usada sin inicializar. Inicialízala antes de usarla.
    5 incompatible types: int cannot be converted to boolean Asignaste un número a un boolean (o similar). Revisa el tipo declarado.
    6 possible lossy conversion from double to int Asignaste un double a un int sin cast. Añade el cast (int) o cambia el tipo de la variable a double.
    7 'javac' is not recognized… JDK no instalado o PATH mal configurado. Reinstala el JDK 21 y revisa JAVA_HOME.
    8 class, public, or interface expected tras un { sin cerrar Llaves desbalanceadas. Cuenta { y }. Usa el sangrado automático del editor.
    9 bad operand types for binary operator '+' Mezclaste tipos incompatibles (p. ej. String + int mal parenthesisado). Usa paréntesis: "a: " + (a + b).
    10 variable a might not have been initialized / cannot find symbol Nombre mal escrito (Java distingue mayúsculas). Revisa ortografía y mayúsculas.

    Herramienta de depuración

    Activa los puntos de interrupción de VS Code: haz clic a la izquierda de la línea y pulsa F5 para ejecutar en modo depuración. Verás el valor de cada variable en cada paso.
