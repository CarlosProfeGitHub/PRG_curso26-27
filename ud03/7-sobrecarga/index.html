    7. Sobrecarga de métodos

    La sobrecarga (overloading) consiste en declarar varios métodos con el mismo nombre pero distinta firma. Java los distingue por sus parámetros, no por su nombre.

    La idea en una frase

    Un mismo nombre puede convivir con distintos tipos de parámetros, siempre que llames a cada versión con argumentos distintos.

    7.1. Qué es la firma

    La firma de un método es el tipo de retorno, el nombre y la lista de tipos de parámetros:

    static double area(double base, double altura)
└───────┬──────────────────────────────────┘
            FIRMA (sin el nombre de los parámetros)

    Qué distingue una firma de otra

    Elemento ¿Forma parte de la firma? ¿Permite sobrecargar?
    Tipo de retorno Sí No
    Nombre del método Sí No (debe ser el mismo)
    Tipo de los parámetros Sí Sí
    Número de parámetros Sí Sí
    Nombre de los parámetros No No

    Por eso esto no compila:

    public static int doble(int n) { return n * 2; }
public static double doble(int n) { return n * 2.0; }   // ❌ misma firma

    Y esto sí:

    public static int doble(int n) { return n * 2; }
public static double doble(double n) { return n * 2.0; }  // ✅ distinto parámetro

    public class Mostrar {

    public static void mostrar(String texto) {
        System.out.println(texto);
    }

    public static void mostrar(String texto, int repeticiones) {
        for (int i = 0; i < repeticiones; i++) {
            System.out.println(texto);
        }
    }

    public static void mostrar(String etiqueta, double valor, int decimales) {
        System.out.printf("%s: %." + decimales + "f%n", etiqueta, valor);
    }

    public static void main(String[] args) {
        mostrar("Hola");                       // Hola
        mostrar("=", 40);                      // 40 líneas de "="
        mostrar("Total", 1234.5678, 2);        // Total: 1234,57
    }
}

    El separador decimal depende del sistema

    printf("%.2f", 1234.5678) imprime 1234,57 con la configuración regional española (coma decimal), no 1234.57. Java decide el separador a partir de la configuración del sistema operativo. No es un error del código, es el comportamiento correcto.

    Por qué la sobrecarga mejora el código

    Sin sobrecarga Con sobrecarga
    mostrarTexto(String) mostrar(String)
    mostrarRepetido(String, int) mostrar(String, int)
    mostrarDecimal(String, double, int) mostrar(String, double, int)

    Cuatro nombres para la misma idea obligan a recordar qué hace cada uno. Un solo nombre con sobrecarga deja que la firma haga el trabajo.

    !!! warning "Reglas de la sobrecarga**

    • Los métodos deben estar en la misma clase.
    • Solo cambia el tipo de retorno no sirve.
    • Si tienes dudas, cambia también el nombre. La sobrecarga es una comodidad, no una obligación.

    7.4. Cuándo sobrecargar y cuándo no

    Situación ¿Sobrecargar? Motivo
    doble(int) y doble(double) Sí El nombre conceptual es el mismo.
    area(lado) y area(base, altura) Sí Dos formas de calcular un área.
    sumar(int, int) y unir(String, String) No Son acciones distintas.
    mostrar() y guardar() No Nombres autoexplicativos, no necesitas sobrecargar.
    Un método de 80 líneas con 6 parámetros No El problema es el método, no la sobrecarga.

    Sobrecargar no es una excusa para el método gigante

    Un método con 6 parámetros de tipos distintos y 80 líneas no es "flexible": es imposible de usar. Si te ves en esa situación, el problema es que faltan más métodos pequeños, no más firmas del mismo.

    7.5. La relación con la herencia

    Lo verás en UD08

    La sobrecarga se combina con la herencia cuando una subclase redefine un método con la misma firma (eso se llama sobrescritura o overriding). La diferencia clave:

    Sobrecarga (overloading) Sobrescritura (overriding)
    Mismo nombre, distinta firma Mismo nombre, misma firma
    En la misma clase En clases distintas (herencia)
    Se añade comportamiento Se cambia el comportamiento
    UD03 · Esta unidad UD08 · POO II

    No los confundas: un doble(int) y un doble(double) en la misma clase son sobrecarga. Un método que redefine el de su clase padre es sobrescritura.
