    /*
 * Programa: GestionFlota
 * Descripción: Analiza los kilometrajes de una flota de vehículos y
 *              calcula la bonificación de cada conductor según sus
 *              kilómetros realizados.
 * Autor: Ana Pérez
 * Fecha: 2026-10-29
 */
import java.util.Scanner;

public class GestionFlota {

    // ---------- Constantes de clase ----------
    static final int MAXIMO_VEHICULOS = 50;
    static final int KM_BONIFICACION = 10000;
    static final double IMPORTE_BASE_BONO = 100.0;

    // Posiciones de los datos que devuelve resumenKilometraje()
    static final int POS_MINIMO = 0;
    static final int POS_MAXIMO = 1;
    static final int POS_MEDIA = 2;
    static final int POS_TOTAL = 3;

    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);
        int[] kilometrajes = new int[MAXIMO_VEHICULOS];
        String[] conductores = new String[MAXIMO_VEHICULOS];

        // ---------- Entrada ----------
        System.out.println("=== GESTIÓN DE FLOTA ===");
        System.out.print("Número de vehículos (máx. " + MAXIMO_VEHICULOS + "): ");
        int cantidad = teclado.nextInt();
        teclado.nextLine();

        validarCantidad(cantidad);
        cantidad = Math.min(cantidad, MAXIMO_VEHICULOS);

        for (int i = 0; i < cantidad; i++) {
            System.out.print("Conductor " + (i + 1) + ": ");
            conductores[i] = teclado.nextLine();

            System.out.print("  Kilometraje: ");
            kilometrajes[i] = teclado.nextInt();
            teclado.nextLine();
        }

        // ---------- Procesamiento ----------
        mostrarResumen(kilometrajes, cantidad);

        System.out.println("\n--- BONIFICACIONES ---");
        for (int i = 0; i < cantidad; i++) {
            double bono = calcularBono(kilometrajes[i]);
            System.out.printf("%-10s %6d km -> %7.2f € (%s)%n",
                    conductores[i], kilometrajes[i], bono, categoria(bono));
        }

        teclado.close();
    }

    /** Procedimiento: avisa si la cantidad no está en el rango permitido. */
    static void validarCantidad(int cantidad) {
        if (cantidad < 1 || cantidad > MAXIMO_VEHICULOS) {
            System.out.println("Aviso: la cantidad debe estar entre 1 y "
                    + MAXIMO_VEHICULOS + ".");
        }
    }

    /** Función: devuelve el array de estadísticas [mínimo, máximo, media, total]. */
    static int[] resumenKilometraje(int[] kms, int cantidad) {
        int minimo = kms[0];
        int maximo = kms[0];
        int total = 0;

        for (int i = 0; i < cantidad; i++) {
            if (kms[i] < minimo) {
                minimo = kms[i];                 // Guardamos el nuevo mínimo
            }
            if (kms[i] > maximo) {
                maximo = kms[i];                 // Guardamos el nuevo máximo
            }
            total += kms[i];                     // Acumulador
        }

        return new int[] {minimo, maximo, total / cantidad, total};
    }

    /** Función sobrecargada: recibe el array y delega en la de cinco parámetros. */
    static void mostrarResumen(int[] kms, int cantidad) {
        if (cantidad == 0) {
            return;                              // Salida anticipada
        }
        int[] r = resumenKilometraje(kms, cantidad);
        mostrarResumen(r[POS_TOTAL], r[POS_MEDIA], r[POS_MAXIMO], r[POS_MINIMO]);
    }

    /** Función sobrecargada: muestra las estadísticas ya calculadas. */
    static void mostrarResumen(int total, int media, int maximo, int minimo) {
        System.out.println("\n=== RESUMEN DE LA FLOTA ===");
        System.out.println("Total     : " + total + " km");
        System.out.println("Media     : " + media + " km");
        System.out.println("Máximo    : " + maximo + " km");
        System.out.println("Mínimo    : " + minimo + " km");
    }

    /** Función: calcula el bono de un conductor a partir de sus kilómetros. */
    static double calcularBono(int kilometros) {
        if (kilometros < KM_BONIFICACION) {
            return 0;                            // Sin bono
        }
        return IMPORTE_BASE_BONO + (kilometros - KM_BONIFICACION) * 0.05;
    }

    /** Función: clasifica el bono por tramos. */
    static String categoria(double bono) {
        if (bono < 50) {
            return "Básico";
        } else if (bono < 200) {
            return "Mejorable";
        }
        return "Excelente";
    }
}

    Dónde está cada cosa que aprendiste

    Apartado Dónde aparece en el programa
    Modularidad El main de 25 líneas delega todo en 5 métodos auxiliares
    Métodos estáticos Todos los métodos llevan static
    Procedimientos validarCantidad() y mostrarResumen() devuelven void
    Funciones resumenKilometraje(), calcularBono() y categoria() devuelven valor
    Parámetros Cada método recibe solo los datos que necesita, y por valor
    Salida anticipada En mostrarResumen(), con cantidad == 0
    Sobrecarga Las dos versiones de mostrarResumen()
    Constantes de clase MAXIMO_VEHICULOS, POS_MINIMO… POS_TOTAL
    Devolver varios datos resumenKilometraje() devuelve un int[] de 4 posiciones

    La sobrecarga que hace algo útil

    Compara las dos versiones de mostrarResumen:

    mostrarResumen(kms, cantidad);                      // 2 parámetros: calcula y muestra
mostrarResumen(total, media, maximo, minimo);      // 4 parámetros: solo muestra

    La primera reutiliza la segunda: calcula el array y delega en la versión que ya sabe imprimirlo. Es la forma más limpia de escribir dos versiones que hacen cosas relacionadas.

    La trampa del array de resultados

    1
2
    return new int[] {minimo, maximo, total / cantidad, total};
//         0           1          2                   3

    El significado de cada posición depende del orden con el que lo escribas. Si mañana cambias el orden dentro del método, main leerá datos equivocados sin ningún error de compilación.

    Por eso el método se llama resumenKilometraje y las posiciones tienen constantes con nombre (POS_MINIMO…). Si inviertes el orden en el return, tendrás que cambiar también las constantes y todas las llamadas.

    Antes de continuar

    1. Cambia IMPORTE_BASE_BONO a 200.0 y vuelve a ejecutar. ¿Qué bonificaciones cambian?
    2. Elimina el return; de la primera versión de mostrarResumen() y comprueba qué pasa con cantidad = 0.
    3. Añade un cuarto parámetro String titulo a mostrarResumen() y actualiza las dos llamadas. Comprueba que sigue funcionando.
