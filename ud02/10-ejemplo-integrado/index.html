    /*
 * Programa: InformeNotas
 * Descripción: Lee las notas de una clase por teclado y muestra
 *              un informe con el número de aprobados, la media,
 *              la nota máxima y la clasificación de cada alumno.
 * Autor: Ana Pérez
 * Fecha: 2026-10-15
 */
import java.util.Scanner;

public class InformeNotas {

    // Constantes: no cambian nunca
    static final int APROBADO = 5;
    static final int NUM_NOTAS = 10;

    public static void main(String[] args) {

        // ---------- 1. DECLARACIÓN DE DATOS ----------
        Scanner teclado = new Scanner(System.in);
        int contador = 0;
        int suma = 0;
        int aprobados = 0;
        int notaMaxima = Integer.MIN_VALUE;   // Todavía no hay ninguna nota
        int nota;

        // ---------- 2. LECTURA DE DATOS ----------
        System.out.println("Introduce las notas de la clase.");
        System.out.println("Escribe un número negativo para terminar la lectura.\n");

        do {
            System.out.print("Nota del alumno " + (contador + 1) + ": ");
            nota = teclado.nextInt();

            // Aserción: el bucle solo debe continuar con notas dentro de rango
            assert nota <= 10 : "La nota no puede superar el 10";

            // Ignore las notas que cortan la lectura
            if (nota < 0) {
                break;                  // Sentencia de salto: fin de la entrada
            }

            // ---------- 3. PROCESO ----------
            suma += nota;               // Acumulador
            contador++;                 // Contador
            if (nota >= APROBADO) {
                aprobados++;            // Contador condicional
            }
            if (nota > notaMaxima) {    // El máximo aún no existe al principio
                notaMaxima = nota;
            }

        } while (contador < NUM_NOTAS);

        // ---------- 4. SALIDA DE INFORMACIÓN ----------
        System.out.println("\n---- INFORME DE LA CLASE ----");

        // Sin notas introducidas no podemos calcular la media
        if (contador == 0) {
            System.out.println("No se ha introducido ninguna nota.");
        } else {
            double media = (double) suma / contador;

            System.out.println("Alumnos evaluados : " + contador);
            System.out.println("Aprobados          : " + aprobados);
            System.out.printf("Media de la clase : %.2f%n", media);
            System.out.println("Nota máxima       : " + notaMaxima);
            System.out.println("Situación         : " + situacion(aprobados, contador));
        }

        teclado.close();
    }

    /**
     * Determina la situación de la clase según el porcentaje de aprobados.
     *
     * @param aprobados número de alumnos aprobados
     * @param total     número total de alumnos evaluados
     * @return un texto con la situación de la clase
     */
    public static String situacion(int aprobados, int total) {
        double porcentaje = (aprobados * 100.0) / total;

        // Selección múltiple encadenada
        if (porcentaje < 25) {
            return "Clase muy floja";
        } else if (porcentaje < 50) {
            return "Clase floja";
        } else if (porcentaje < 75) {
            return "Clase normal";
        } else if (porcentaje < 90) {
            return "Clase buena";
        }
        return "Clase excelente";
    }
}

    Dónde está cada cosa que aprendiste

    Apartado Dónde aparece en el programa
    Selección if (nota < 0), if (contador == 0) y toda la cadena else if de situacion()
    Repetición do … while (contador < NUM_NOTAS)
    Sentencia de salto break al introducir una nota negativa
    Contadores y acumuladores contador, suma, aprobados
    División entera evitada (double) suma / contador y aprobados * 100.0 / total
    Documentación Cabecera, comentarios de zona y Javadoc en situacion()
    Constantes APROBADO y NUM_NOTAS con static final

    Dos detalles que no son obvios

    • Integer.MIN_VALUE como valor inicial de notaMaxima: no puedes empezar por 0, porque si todas las notas fueran negativas, el máximo se quedaría en 0. Empezando por el valor más pequeño posible, la primera nota siempre será el máximo.
    • break antes de contar: si no lo pusieras, la nota negativa se sumaría y se contaría como un alumno más. El break sale del bucle antes de procesar.

    Antes de continuar

    1. Cambia APROBADO por 7 y vuelve a ejecutar. ¿Qué cambia en el informe?
    2. Elimina el break y comprueba qué ocurre. Explica el resultado.
    3. Elimina el (double) de la media y comprueba qué pasa con notas como 7 y 8.
