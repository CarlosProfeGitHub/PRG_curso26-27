    16. Glosario

    Término Definición
    Acumulador Variable que guarda la suma (u otra operación) parcial a lo largo de un bucle. Se inicializa con el valor neutro de la operación.
    Aserción (assert) Comprobación que debe ser cierta; si es falsa, el programa lanza AssertionError. Está desactivada por defecto.
    Bloque de sentencias Conjunto de sentencias entre {} que se ejecuta como una sola unidad y delimita un nuevo ámbito.
    Bucle controlado por contador Bucle cuyo número de iteraciones se conoce de antemano (for, for-each).
    Bucle controlado por suceso Bucle que se repite mientras se cumpla una condición (while, do-while).
    Bucle infinito Bucle cuya condición nunca se vuelve falsa.
    Caja blanca Tipo de prueba que conoce el código interno y comprueba que se ha ejecutado todo.
    Caja negra Tipo de prueba que solo comprueba la salida, sin conocer la implementación.
    Caja de cristal Técnica de traza manual: ejecutar el programa en papel, instrucción a instrucción.
    Caso límite Valor justo en el borde de lo que el programa acepta, o un valor por encima o por debajo.
    Contador Variable que lleva la cuenta de las iteraciones o de los elementos procesados.
    Continue Sentencia de salto que termina la iteración actual y pasa a la siguiente.
    Depuración Proceso de encontrar la causa exacta de un error observando el estado interno del programa.
    Else suspendido (dangling else) else que se asocia al if más cercano que aún no tenga else, y no al que el autor pretendía.
    Expresión Combinación de literales, variables y operadores que produce un valor.
    Fall-through Comportamiento de un switch sin break: la ejecución continúa en el case siguiente.
    Invariante de bucle Condición que debe ser cierta en cada iteración de un bucle. Se comprueba con una aserción.
    Operador condicional El operador ternario ? :, que devuelve un valor u otro según una condición booleana.
    Postcondición Lo que debe ser cierto después de ejecutar un bloque de código. Se comprueba con una aserción.
    Precondición Lo que debe ser cierto antes de ejecutar un bloque de código. Se comprueba con una aserción.
    Punto de interrupción (breakpoint) Marca en el editor que detiene el programa al llegar a esa línea, para poder inspeccionar las variables.
    Salida anticipada (early return) Técnica que consiste en comprobar primero los casos especiales y salir del método con return, reduciendo el anidamiento.
    Sentencia nula Línea que solo contiene ;. Es legal, pero no hace nada.
    Sentencia de salto Instrucción que altera el flujo normal de ejecución (break, continue, return).
    Tabla de decisión Tabla que enumera las combinaciones posibles de las condiciones de un programa y el resultado esperado de cada una.
    Traza Lectura de un programa sin ejecutarlo, anotando el valor de cada variable en cada instrucción.
    Traza de pila (stack trace) Lista de líneas que indica por dónde se ejecutó el programa hasta llegar al error.
    Valor neutro Valor con el que se inicializa un acumulador para no alterar el resultado (0 para sumar, 1 para multiplicar).

    Palabras reservadas usadas en esta unidad

    if · else · switch · case · default · break · continue · return · while · do · for · assert
