# UD08: Composición, Herencia y Polimorfismo

## 📝 Objetivos
- Aplicar relaciones de composición y herencia entre clases.
- Implementar polimorfismo y ligadura dinámica.
- Utilizar clases abstractas e interfaces.

## 📚 Contenidos
1. Relaciones entre clases (Asociación, Composición, Agregación).
2. Herencia (`extends`) y sobrescritura de métodos.
3. Polimorfismo y conversión de tipos (casting).
4. Clases abstractas e interfaces (`interface`).
