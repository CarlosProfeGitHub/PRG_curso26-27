# UD07: Colecciones y Funciones Lambda

## 📝 Objetivos
- Utilizar la jerarquía de la Java Collections Framework.
- Elegir la estructura de datos adecuada (Listas, Conjuntos, Mapas).
- Introducción a la programación funcional y expresiones Lambda.

## 📚 Contenidos
1. Interfaz `Collection`: `List`, `Set`, `Map`.
2. Clases `ArrayList`, `LinkedList`, `HashSet`, `HashMap`.
3. Iteración sobre colecciones y comparadores.
4. Expresiones Lambda y Streams básicos.
