# UD02: Utilización de Objetos

## 📝 Objetivos
- Comprender el concepto de objeto y clase en programación orientada a objetos.
- Utilizar clases predefinidas del lenguaje (String, Math, Scanner, etc.).
- Gestionar referencias y llamadas a métodos.

## 📚 Contenidos
1. Objetos, clases y métodos.
2. Instanciación y uso de objetos.
3. Métodos estáticos e instanciados.
4. Entrada y salida de datos (Scanner, System.out).
