# UD05: Desarrollo de clases

## 📝 Objetivos
- Diseñar y crear clases propias respetando el encapsulamiento.
- Definir atributos, métodos y constructores.
- Comprender la visibilidad y el ámbito de las variables.

## 📚 Contenidos
1. Definición de clases y objetos propios.
2. Atributos y métodos. Constructores.
3. Modificadores de acceso (encapsulación).
4. Sobrecarga de métodos.
