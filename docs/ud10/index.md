# UD10: Acceso a Bases de datos

## 📝 Objetivos
- Conectar una aplicación orientada a objetos con un sistema de gestión de bases de datos relacionales (RDBMS).
- Realizar consultas y operaciones CRUD mediante JDBC o frameworks ORM.

## 📚 Contenidos
1. Arquitectura de acceso a datos (JDBC).
2. Conexiones, sentencias (`Statement`, `PreparedStatement`) y conjuntos de resultados (`ResultSet`).
3. Patrón DAO (Data Access Object).
