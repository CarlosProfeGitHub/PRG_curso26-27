# UD03: Estructuras de control y Excepciones

## 📝 Objetivos
- Implementar estructuras condicionales e iterativas.
- Manejar el flujo de ejecución del programa.
- Tratar excepciones básicas para lograr programas robustos.

## 📚 Contenidos
1. Estructuras de selección (`if`, `switch`).
2. Estructuras de repetición (`while`, `do-while`, `for`).
3. Conceptos básicos de captura de excepciones (`try-catch`).
